**Goal:** Implement MathMap — a mapping that transforms coordinates using mathematical expressions parsed and evaluated at runtime.

**Architecture:** Split into sub-modules (opcode, token, parser, evaluator, rng, mod) under `crates/ast-core/src/mappings/mathmap/`. Uses a logos-based tokenizer, a Pratt (precedence-climbing) parser that emits postfix opcodes, and a stack-based VM evaluator. The RNG is an exact port of the C library's combined shuffle-table algorithm.

**Tech Stack:** Rust 2024, logos 0.16 (tokenizer), no other new dependencies.

```rust
    let s = lex.slice();
    // Handle Fortran-style 'd' or 'D' exponent

    s.parse::<f64>().unwrap_or(0.0)
```

```rust
/// Tokenize an expression string, returning tokens with their spans.
pub(crate) fn tokenize(input: &str) -> Result<Vec<(Token, &str)>, String> {
    let mut lex = Token::lexer(input);
    let mut tokens = Vec::new();
    while let Some(tok_result) = lex.next() {
        match tok_result {
            Ok(tok) => tokens.push((tok, lex.slice())),
            Err(()) => {
                return Err(format!(
                    "unexpected character at position {}",
                    lex.span().start
                ));
            }
        }
    }
    Ok(tokens)
}
```

### Task 4: Implement the Pratt parser

**Files:**
- Modify: `crates/ast-core/src/mappings/mathmap/parser.rs`

- [ ] **Step 1: Implement the parser**

The parser takes a cleaned expression string (e.g. `"y=sin(x1)+2.5"`) and produces a `CompiledExpr`. It:
1. Splits on `=` to get the LHS variable name and RHS expression.
2. Validates the LHS is a valid output variable name.
3. Parses the RHS using precedence climbing.
4. Emits opcodes in postfix order.

The precedence table (from C symbol table, higher = tighter binding):
- 19: literals, constants, variables, function calls
- 18: `**` (right-to-left)
- 17: unary `+`, `-`, `!`, `.not.`
- 14: `*`, `/`
- 13: `+`, `-` (binary)
- 12: `<<`, `>>`
- 11: `<`, `<=`, `>`, `>=`, `.lt.`, `.le.`, `.gt.`, `.ge.`
- 10: `==`, `!=`, `.eq.`, `.ne.`
- 9: `&` (bitwise AND)
- 8: `^` (bitwise XOR)
- 7: `|` (bitwise OR)
- 6: `&&`, `.and.`
- 5: `^^`
- 4: `||`, `.or.`
- 3: `.eqv.`, `.neqv.`, `.xor.`

The ternary `?:` is handled specially — when a `?` is encountered, parse the condition with a precedence cutoff, then parse the true branch up to `:`, then parse the false branch.

Key details:
- Function calls: when an identifier is followed by `(`, it's a function. Parse comma-separated arguments. Emit args then the function opcode.
- Variable-arity `max` and `min`: count the arguments, emit them all, then emit the opcode followed by the count as a constant.
- Variable references: `x1`, `x2`, ... are input variables (1-based index). Emit `LdVar` with the 0-based index stored as a constant.
- Constants: numeric literals. Emit `LdCon` with the value stored in the constants array.

The parser tracks max stack depth during compilation for the evaluator.

```rust
impl MathMap {
    /// Create a new MathMap.
    ///
    /// `nin` and `nout` are the number of input and output coordinates.
    /// `fwd` contains `nout` forward expression strings (x→y).
    /// `inv` contains `nin` inverse expression strings (y→x).
    ///
    /// Expressions are compiled immediately. Returns an error if any
    /// expression is syntactically invalid or references out-of-range
    /// variables.
    pub fn new(nin: usize, nout: usize, fwd: &[&str], inv: &[&str]) -> AstResult<Self> {
        // Validate counts
        if fwd.len() < nout {
            return Err(AstError::new(
                ErrorCode::Badni,
                format!("need at least {} forward expressions, got {}", nout, fwd.len()),
            ));
        }
        if inv.len() < nin {
            return Err(AstError::new(
                ErrorCode::Badni,
                format!("need at least {} inverse expressions, got {}", nin, inv.len()),
            ));
        }

        // Clean expressions (lowercase, strip whitespace)
        let fwd_clean: Vec<String> = fwd.iter().map(|s| clean_expression(s)).collect();
        let inv_clean: Vec<String> = inv.iter().map(|s| clean_expression(s)).collect();

        // Compile forward expressions
        let mut fwd_compiled = Vec::with_capacity(fwd_clean.len());
        for expr in &fwd_clean {
            fwd_compiled.push(parser::compile_expression(expr, nin)?);
        }

        // Compile inverse expressions
        let mut inv_compiled = Vec::with_capacity(inv_clean.len());
        for expr in &inv_clean {
            inv_compiled.push(parser::compile_expression(expr, nout)?);
        }

        let fwd_stack_size = fwd_compiled.iter().map(|e| e.stack_size).max().unwrap_or(1);
        let inv_stack_size = inv_compiled.iter().map(|e| e.stack_size).max().unwrap_or(1);

        Ok(Self {
            nin,
            nout,
            fwd_exprs: fwd_clean,
            inv_exprs: inv_clean,
            fwd_compiled,
            inv_compiled,
            fwd_stack_size,
            inv_stack_size,
            rng: MathMapRng::new(),
            simp_fi: None,
            simp_if: None,
            inverted: false,
            do_not_simplify: false,
        })
    }

    // Attribute accessors ...
    pub fn simp_fi(&self) -> bool { self.simp_fi.unwrap_or(false) }
    pub fn simp_if(&self) -> bool { self.simp_if.unwrap_or(false) }
    pub fn set_simp_fi(&mut self, val: bool) { self.simp_fi = Some(val); }
    pub fn set_simp_if(&mut self, val: bool) { self.simp_if = Some(val); }
    pub fn seed(&self) -> i32 { self.rng.seed }
    pub fn set_seed(&mut self, seed: i32) {
        self.rng.seed = seed;
        self.rng.seed_set = true;
        self.rng.reset();
    }
}

/// Clean an expression: lowercase, strip all whitespace.
fn clean_expression(s: &str) -> String {
    s.chars().filter(|c| !c.is_whitespace()).flat_map(|c| c.to_lowercase()).collect()
}
```

Serialization tokens (matching C Dump/Load exactly):
- `Nfwd` — number of forward expressions (only written if != nout)
- `Ninv` — number of inverse expressions (only written if != nin)
- `Fwd1`, `Fwd2`, ... — forward expression strings (quoted)
- `Inv1`, `Inv2`, ... — inverse expression strings (quoted)
- `SimpFI` — forward-inverse simplification flag
- `SimpIF` — inverse-forward simplification flag

```rust
impl Serializable for MathMap {
    fn class_name(&self) -> &'static str {
        "MathMap"
    }

    fn to_node(&self) -> AstResult<Node> {
        let mut node = Node::new(self.class_name());
        node.class_comment = Some("Transformation using mathematical functions".to_string());

        // Write intrinsic nin/nout (undo inversion for serialization)
        write_mapping_base(&mut node, self);

        // Nfwd — only if differs from nout
        let (nin, nout) = if self.inverted {
            (self.nout, self.nin)
        } else {
            (self.nin, self.nout)
        };

        if self.fwd_exprs.len() != nout {
            node.push_int("Nfwd", self.fwd_exprs.len() as i64,
                Some("Number of forward transformation functions".to_string()));
        } else {
            node.push_unset("Nfwd", NodeValue::Int(self.fwd_exprs.len() as i64),
                Some("Number of forward transformation functions".to_string()));
        }

        // Forward expressions
        for (i, expr) in self.fwd_exprs.iter().enumerate() {
            let key = format!("Fwd{}", i + 1);
            let comment = format!("Forward function {}", i + 1);
            node.push_string(&key, expr, Some(comment));
        }

        // Ninv — only if differs from nin
        if self.inv_exprs.len() != nin {
            node.push_int("Ninv", self.inv_exprs.len() as i64,
                Some("Number of inverse transformation functions".to_string()));
        } else {
            node.push_unset("Ninv", NodeValue::Int(self.inv_exprs.len() as i64),
                Some("Number of inverse transformation functions".to_string()));
        }

        // Inverse expressions
        for (i, expr) in self.inv_exprs.iter().enumerate() {
            let key = format!("Inv{}", i + 1);
            let comment = format!("Inverse function {}", i + 1);
            node.push_string(&key, expr, Some(comment));
        }

        // SimpFI
        let simp_fi_val = self.simp_fi.unwrap_or(false) as i64;
        if self.simp_fi.is_some() {
            node.push_int("SimpFI", simp_fi_val,
                Some(if simp_fi_val != 0 { "Forward-inverse pairs may simplify" } else { "Forward-inverse pairs do not simplify" }.to_string()));
        } else {
            node.push_unset("SimpFI", NodeValue::Int(simp_fi_val),
                Some("Forward-inverse pairs do not simplify".to_string()));
        }

        // SimpIF
        let simp_if_val = self.simp_if.unwrap_or(false) as i64;
        if self.simp_if.is_some() {
            node.push_int("SimpIF", simp_if_val,
                Some(if simp_if_val != 0 { "Inverse-forward pairs may simplify" } else { "Inverse-forward pairs do not simplify" }.to_string()));
        } else {
            node.push_unset("SimpIF", NodeValue::Int(simp_if_val),
                Some("Inverse-forward pairs do not simplify".to_string()));
        }

        // Seed
        let seeded = self.rng.seed_set;
        if seeded {
            node.push_int("Seeded", 1,
                Some("Explicit random number seed set".to_string()));
            node.push_int("Seed", self.rng.seed as i64,
                Some("Random number seed value".to_string()));
        } else {
            node.push_unset("Seeded", NodeValue::Int(0),
                Some("No random number seed set".to_string()));
            node.push_unset("Seed", NodeValue::Int(self.rng.seed as i64),
                Some("Default random number seed used".to_string()));
        }

        Ok(node)
    }

    fn from_node(node: &Node) -> AstResult<Self> {
        let base = read_mapping_base(node);

        // Get true nin/nout (before inversion)
        let (nin, nout) = if base.inverted {
            (base.nout, base.nin)
        } else {
            (base.nin, base.nout)
        };

        let nfwd = node.get_int("Nfwd", nout as i64) as usize;
        let ninv = node.get_int("Ninv", nin as i64) as usize;

        // Read forward expressions
        let mut fwd_exprs = Vec::with_capacity(nfwd);
        for i in 0..nfwd {
            let key = format!("Fwd{}", i + 1);
            fwd_exprs.push(node.get_string(&key, ""));
        }

        // Read inverse expressions
        let mut inv_exprs = Vec::with_capacity(ninv);
        for i in 0..ninv {
            let key = format!("Inv{}", i + 1);
            inv_exprs.push(node.get_string(&key, ""));
        }

        // Build expressions as string slices for the constructor
        let fwd_refs: Vec<&str> = fwd_exprs.iter().map(|s| s.as_str()).collect();
        let inv_refs: Vec<&str> = inv_exprs.iter().map(|s| s.as_str()).collect();

        let mut map = MathMap::new(nin, nout, &fwd_refs, &inv_refs)?;

        // Restore attributes
        // SimpFI/SimpIF: -INT_MAX means unset in C
        let simp_fi_raw = node.get_int("SimpFI", i64::MIN);
        if simp_fi_raw != i64::MIN {
            map.simp_fi = Some(simp_fi_raw != 0);
        }
        let simp_if_raw = node.get_int("SimpIF", i64::MIN);
        if simp_if_raw != i64::MIN {
            map.simp_if = Some(simp_if_raw != 0);
        }

        // Seed
        let seeded = node.get_int("Seeded", 0) != 0;
        if seeded {
            let seed = node.get_int("Seed", 0) as i32;
            map.set_seed(seed);
        }

        map.do_not_simplify = base.do_not_simplify;
        if base.inverted {
            map.invert();
        }
        Ok(map)
    }
}
```

## Implementation Notes for the Engineer

### Expression Language Grammar

The expression language is case-insensitive (cleaned to lowercase). Variables:
- Forward transform inputs: `x` (alias for `x1`), `x1`, `x2`, ..., `xN`
- Forward transform outputs: `y` (alias for `y1`), `y1`, `y2`, ..., `yM`
- Inverse transform inputs: `y` (alias for `y1`), `y1`, `y2`, ..., `yM`
- Inverse transform outputs: `x` (alias for `x1`), `x1`, `x2`, ..., `xN`

An expression has the form `<output_var> = <expr>` or just `<expr>` (assigned to the Nth output).

The C library supports "extra" forward/inverse expressions beyond the minimum needed. Extra expressions define temporary variables that can be referenced by later expressions. The first `nout` forward expressions define y1..yN; any additional ones define temporary names that can be used by subsequent expressions. We should support this for compatibility but it can be deferred if complex.

### Key Differences from C Implementation

1. **No vectorized evaluation**: The C evaluator processes all points at once using vector stacks. For simplicity, the Rust port evaluates one point at a time. This is acceptable for correctness; performance optimization can come later.

2. **RNG is cloned per transform call**: Since `transform` takes `&self`, we clone the RNG. This means random sequences differ from C when the same MathMap is used multiple times. This is acceptable — the C library's random sequences are also non-reproducible across different program runs unless `Seed` is explicitly set.

3. **Static variables in C**: The C code uses `static` locals for caching (LogGamma, Poisson thresholds, etc.). In Rust, we compute these each time or use `std::sync::LazyLock` for the purely-constant ones.

### BAD Value Semantics Summary

| Operation | BAD handling |
|-----------|-------------|
| Most unary (sin, cos, etc.) | BAD in → BAD out |
| Most binary (add, mul, etc.) | Either BAD → BAD out |
| IsBad | BAD → 1.0, good → 0.0 (never produces BAD) |
| And (tri-state) | BAD && 0 = 0, BAD && nonzero = BAD |
| Or (tri-state) | BAD \|\| nonzero = 1, BAD \|\| 0 = BAD |
| Qif (ternary) | No BAD check on condition (BAD is nonzero → takes true branch) |
| Max/Min | Either BAD → BAD result (via pairwise reduction) |
| Rand/Gauss | Arguments checked for BAD normally |
