# Mapping Simplification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the full mapping simplification engine — CmpMap flattening, iterative merge loop, and per-class merge rules for all mapping types — so that complex mapping chains collapse into simpler equivalents.

**Architecture:** A new `simplify.rs` module implements the core engine (flatten CmpMap trees → merge adjacent pairs → reconstruct). Each mapping type implements `try_merge()` on the Mapping trait for type-specific merge rules. The merge loop iterates until no more improvements, with frozen flags to prevent infinite oscillation. CmpMap::simplified() delegates to the new engine.

**Tech Stack:** Rust 2024 edition. Uses existing `equal()` and `ast_equal()` for comparison. No new dependencies.

- [ ] **Step 1: Add try_merge to Mapping trait**

    /// Attempt to merge this mapping with an adjacent mapping during
    /// simplification.
    ///
    /// Returns `Some(merged)` if this mapping can absorb `other` into
    /// a single equivalent mapping. Returns `None` if no merge possible.
    /// `series` is true for series composition. `self_inv` and `other_inv`

    fn try_merge(
        &self,

- [ ] **Step 2: Create simplify.rs with flatten**

Create `crates/starlink-ast/src/mappings/simplify.rs`:

The `flatten` function decomposes a CmpMap into a flat list of
`(DynMapping, bool)` pairs (mapping + effective invert flag):

```rust
pub(crate) fn flatten(
    mapping: &dyn Mapping,
    inv: bool,
    series: bool,
) -> Vec<(DynMapping, bool)>
```

For CmpMap:
- If CmpMap's kind matches `series` and it's not marked
  do-not-simplify: recursively expand children.
- If CmpMap is inverted: swap child order (for series) and
  flip both children's invert flags.
- Otherwise: return single-element list.

For non-CmpMap: clone via `simplified()` and return single element.

Uses `as_any().downcast_ref::<CmpMap>()` to detect CmpMaps.
Accesses CmpMap's private fields — since simplify.rs is in the
same `mappings` module, it can access `pub(super)` or use
accessor methods. **Alternative**: add `pub(crate)` accessor
methods to CmpMap for `first()`, `second()`, `kind()`.

- [ ] **Step 3: Implement merge_loop**

The iterative merge loop:

```rust
pub(crate) fn merge_loop(
    list: &mut Vec<(DynMapping, bool)>,
    series: bool,
)
```

Algorithm:
1. Walk adjacent pairs.
2. Try inverse-pair cancellation (via `equal` ignoring inversion).
3. Try left.try_merge(right) then right.try_merge(left).
4. On success: replace pair with result, restart from position.
5. Repeat until no improvements in a full pass.
6. Post-loop: remove UnitMaps from series lists.

Frozen flags: track which positions have been merged to prevent
oscillation. If position i was modified on the previous pass and
gets modified again → freeze it.

- [ ] **Step 4: Implement reconstruct**

```rust
pub(crate) fn reconstruct(
    list: Vec<(DynMapping, bool)>,
    series: bool,
) -> AstResult<DynMapping>
```

Build a CmpMap tree from the flat list. Single element → return
directly. Empty → UnitMap. Multiple → fold into nested CmpMaps.

Apply invert flags: if a mapping's effective invert differs from
its stored `is_inverted()`, call `invert()` on a clone.

- [ ] **Step 5: Implement simplify_mapping entry point**

```rust
pub(crate) fn simplify_mapping(mapping: &dyn Mapping) -> AstResult<DynMapping>
```

Orchestrates: flatten → merge_loop → reconstruct.

For non-CmpMap input: just call the mapping's own `simplified()`.
For CmpMap: use the full engine.

- [ ] **Step 1: UnitMap try_merge**

```rust
fn try_merge(&self, other: &dyn Mapping, series: bool,
             _self_inv: bool, _other_inv: bool) -> Option<DynMapping> {
    if !series {
        // Parallel: merge adjacent UnitMaps
        let other_unit = other.as_any().downcast_ref::<UnitMap>()?;
        Some(Box::new(UnitMap::new(self.ncoord + other_unit.ncoord)))
    } else {
        None // Series UnitMap removal handled by post-loop cleanup
    }
}
```

- [ ] **Step 2: ZoomMap try_merge**

```rust
fn try_merge(&self, other: &dyn Mapping, series: bool,
             self_inv: bool, other_inv: bool) -> Option<DynMapping> {
    if !series { return None; }
    let other_zoom = other.as_any().downcast_ref::<ZoomMap>()?;
    if self.ncoord != other_zoom.ncoord { return None; }
    let f1 = if self_inv { 1.0 / self.factor } else { self.factor };
    let f2 = if other_inv { 1.0 / other_zoom.factor } else { other_zoom.factor };
    let product = f1 * f2;
    if ast_equal(product, 1.0) {
        Some(Box::new(UnitMap::new(self.ncoord)))
    } else {
        Some(Box::new(ZoomMap::new(self.ncoord, product).ok()?))
    }
}
```

- [ ] **Step 3: ShiftMap try_merge**

```rust
fn try_merge(&self, other: &dyn Mapping, series: bool,
             self_inv: bool, other_inv: bool) -> Option<DynMapping> {
    if !series { return None; }
    let other_shift = other.as_any().downcast_ref::<ShiftMap>()?;
    if self.shift.len() != other_shift.shift.len() { return None; }
    let mut combined = Vec::with_capacity(self.shift.len());
    for i in 0..self.shift.len() {
        let s1 = if self_inv { -self.shift[i] } else { self.shift[i] };
        let s2 = if other_inv { -other_shift.shift[i] } else { other_shift.shift[i] };
        combined.push(s1 + s2);
    }
    if combined.iter().all(|&s| ast_equal(s, 0.0)) {
        Some(Box::new(UnitMap::new(self.shift.len())))
    } else {
        Some(Box::new(ShiftMap::new(combined)))
    }
}
```

- [ ] **Step 1: WinMap try_merge**

WinMap composes with WinMap, ZoomMap, and ShiftMap:

```rust
fn try_merge(&self, other: &dyn Mapping, series: bool,
             self_inv: bool, other_inv: bool) -> Option<DynMapping> {
    if !series { return None; }
    // Get effective (shift, scale) for self
    let (s1, c1) = self.effective_params(self_inv);
    // Try to get effective (shift, scale) from other
    let (s2, c2) = effective_winmap_params(other, other_inv)?;
    // Compose: out = c2*(c1*x + s1) + s2 = (c2*c1)*x + (c2*s1 + s2)
    let n = s1.len();
    let mut shifts = vec![0.0; n];
    let mut scales = vec![0.0; n];
    for i in 0..n {
        scales[i] = c2[i] * c1[i];
        shifts[i] = c2[i] * s1[i] + s2[i];
    }
    if scales.iter().all(|&s| ast_equal(s, 1.0))
        && shifts.iter().all(|&s| ast_equal(s, 0.0)) {
        Some(Box::new(UnitMap::new(n)))
    } else {
        WinMap::new(&shifts, &scales).ok().map(|m| Box::new(m) as DynMapping)
    }
}
```

Helper `effective_winmap_params` extracts (shifts, scales) from
WinMap, ZoomMap (shifts=0, scales=factor), or ShiftMap (shifts=s,
scales=1). Returns None for other types.

Add `pub(crate) fn effective_params(&self, inv: bool) -> (Vec<f64>, Vec<f64>)`
to WinMap that returns (shifts, scales) accounting for inversion.

- [ ] **Step 2: MatrixMap try_merge**

```rust
fn try_merge(&self, other: &dyn Mapping, series: bool,
             self_inv: bool, other_inv: bool) -> Option<DynMapping> {
    if !series { return None; }
    let other_mat = other.as_any().downcast_ref::<MatrixMap>()?;
    // Get effective forward matrices
    let a = self.effective_matrix(self_inv)?;
    let b = other_mat.effective_matrix(other_inv)?;
    // Compose: B applied after A → product is B * A
    let product = b.dot(&a);
    // Check if identity
    if is_identity_matrix(&product) {
        Some(Box::new(UnitMap::new(product.nrows())))
    } else {
        MatrixMap::new(product).ok().map(|m| Box::new(m) as DynMapping)
    }
}
```

Add `pub(crate) fn effective_matrix(&self, inv: bool) -> Option<Array2<f64>>`
to MatrixMap: returns the forward matrix (or inverse matrix if
inverted).

- [ ] **Step 2: SphMap inverse cancellation**

```rust
fn try_merge(&self, other: &dyn Mapping, series: bool,
             self_inv: bool, other_inv: bool) -> Option<DynMapping> {
    if !series { return None; }
    let other_sph = other.as_any().downcast_ref::<SphMap>()?;
    // SphMap + SphMap^-1 → UnitMap (if one forward, one inverse)
    if self_inv != other_inv
        && self.unit_radius == other_sph.unit_radius
        && ast_equal(self.polar_long, other_sph.polar_long) {
        let n = if self_inv { 2 } else { 3 }; // output dim of first
        Some(Box::new(UnitMap::new(n)))
    } else {
        None
    }
}
```

Wait — SphMap has nin=3, nout=2 (or vice versa when inverted).
When SphMap(3→2) is followed by SphMap^-1(2→3), the result is
UnitMap(3). When SphMap^-1(2→3) is followed by SphMap(3→2), the
result is UnitMap(2). The merge needs to determine which direction
produces the correct identity dimension.

Actually, for the merge loop the key insight is: the `n` for
UnitMap equals the **input dimension of the first** mapping in
the pair, which equals the **output dimension of the pair**.

- [ ] **Step 3: WcsMap, SlaMap, PolyMap inverse cancellation**

These all follow the same pattern: check if the other mapping is
the same type with matching parameters, one inverted and one not →
UnitMap. Use `equal` (ignoring inversion) as the test.

```rust
// Generic pattern for WcsMap, SlaMap, PolyMap:
fn try_merge(&self, other: &dyn Mapping, series: bool,
             self_inv: bool, other_inv: bool) -> Option<DynMapping> {
    if !series || self_inv == other_inv { return None; }
    // Check same type and matching params
    let other_typed = other.as_any().downcast_ref::<Self>()?;
    // Compare ignoring inversion — check key fields
    if self.params_equal(other_typed) {
        Some(Box::new(UnitMap::new(self.nin())))
    } else {
        None
    }
}
```

Each type defines a private `params_equal` that compares the
type-specific fields (excluding the inverted flag).
