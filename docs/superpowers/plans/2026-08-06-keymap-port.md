# KeyMap Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port AST's `KeyMap` class to `crates/starlink-ast/src/keymap/`, with entry storage in a `std::collections::HashMap`, the full `ConvertValue` type-conversion matrix, all seven `SortBy` modes, a `Serializable` round trip that is byte-exact against C except for the `MapSz` card, and `AnyObject::KeyMap` wired into both serialization dispatch functions.

**Architecture:** The design is fixed by `docs/superpowers/specs/2026-08-06-keymap-port-design.md`; read it before starting.
Entries live in `HashMap<String, MapEntry>` keyed by the already-normalized key, and the only part of C's chained bucket table that survives is the arithmetic needed to compute the `MapSz` card at dump time.
Ordering is computed at read-out from `member` / `keymember` / `KeyCmp` rather than maintained in a sorted linked list, which is what makes the dump idempotent and independent of insertion order.
The module is six files, following the multi-file layout `crates/starlink-ast/src/regions/` already uses.

**Tech Stack:** Rust 2024 edition, `cargo test` / `cargo fmt` / `cargo clippy`.
The authority for every behavioral question is `reference/starlink-ast/src/keymap.c` (11,484 lines).
Where the C source does not settle a question, build a C oracle probe under `tools/oracle_fixtures/` following `docs/issues/c-oracle-probe-recipe.md`.

So "the two KeyMap fixtures regenerated; both simplify-fixture consumers green" is not reachable by porting KeyMap alone — no consumer reads those files, and regenerating them would require porting `StcResourceProfile`, `Stc`, and `StcObsDataLocation`.

**Resolution.** The fixtures stay exactly as they are.

`PLAN.md`'s fixture table stays.
Round-trip coverage instead comes from two places (Task 17): hand-built KeyMaps exercising every type code and both `nel` cases, and a targeted test that lifts the KeyMap subtree out of `cap_timemap_02.map` (found by scanning for the `Begin KeyMap` / `End KeyMap` markers), parses it, dumps it, and compares card-for-card modulo the reordering the design mandates.
That gives the fixture's real C-generated bytes as an oracle without pretending a `StcResourceProfile` loads.

### `testobjectkeymap.c` is deferred, not ported

All four of its test functions (`TestCreate`, `TestCopy`, `TestToString`, `TestObjSize`) exercise the **protected** `astGetKeyMap` / `astHasKeyMap` on the Object class, plus `astGetObjSize` and `astSame`.
The Object-associated retained KeyMap is an explicit spec Non-goal (`object.c:1736`, `object.c:2480`), `astGetObjSize` has no analogue in an owned-value port, and `astSame` is pointer identity, which owned values do not have.

**Resolution.** `testkeymap.c` is ported in full (Task 16).
`testobjectkeymap.c` is recorded in `PLAN.md`'s migration tracker as deferred, naming the Object machinery it waits on (Task 18).
It is not a partial port and not a silent drop.

### Task 2: Module skeleton and `entry.rs`

The entry value model.
C stores nine typed value arrays behind a discriminant (`Entry.type`) plus `nel` (0 = scalar, >0 = vector length) plus `defined` (0 only for `AST__UNDEFTYPE`).
Rust folds `type` + `nel` + the payload into one enum: the variant is the type code, and `Scalar1D` carries the scalar/vector distinction.
`AST__POINTERTYPE` (code 6) is omitted per the spec — no Rust caller can hold a raw C pointer meaningfully — but the code number stays reserved so `from_node` can report it as unknown.

```rust
//! Entry storage: the AST type codes, the scalar-or-vector payload, and
//! the per-entry bookkeeping C keeps in `struct AstMapEntry`.

use crate::serial::AnyObject;

/// The AST data type of a KeyMap entry.
///
/// The discriminants are C's `AST__*TYPE` constants from `ast.h`.
/// `AST__BADTYPE` (0) is C's "no type" marker and has no variant;
/// `AST__POINTERTYPE` (6) holds a raw C pointer and is not representable
/// in the Rust API, so its code is reserved but unhandled.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum AstType {
    /// `AST__INTTYPE`: `int`.
    Int = 1,
    /// `AST__DOUBLETYPE`: `double`.
    Double = 2,
    /// `AST__STRINGTYPE`: null-terminated string.
    String = 3,
    /// `AST__OBJECTTYPE`: a nested AST Object.
    Object = 4,
    /// `AST__FLOATTYPE`: `float`.
    Float = 5,
    /// `AST__SINTTYPE`: `short int`.
    SInt = 7,
    /// `AST__UNDEFTYPE`: the key exists but has no value.
    Undef = 8,
    /// `AST__BYTETYPE`: `unsigned char`.
    Byte = 9,
    /// `AST__KINTTYPE`: 64-bit integer.
    KInt = 10,
}

impl AstType {
    /// Every representable type, in ascending code order.
    pub const ALL: [AstType; 9] = [
        AstType::Int,
        AstType::Double,
        AstType::String,
        AstType::Object,
        AstType::Float,
        AstType::SInt,
        AstType::Undef,
        AstType::Byte,
        AstType::KInt,
    ];

    /// The C `AST__*TYPE` code for this type.
    pub fn code(self) -> i64 {
        self as i64
    }

    /// The type for a C `AST__*TYPE` code, or `None` when the code is
    /// `AST__BADTYPE`, `AST__POINTERTYPE`, or out of range.
    pub fn from_code(code: i64) -> Option<AstType> {
        AstType::ALL.into_iter().find(|t| t.code() == code)
    }

    /// The comment written alongside the `Typ%d` card, matching
    /// `DumpEntry` in `keymap.c`.
    pub fn type_comment(self) -> &'static str {
        match self {
            AstType::String => "Item data type (string)",
            AstType::Object => "Item data type (AST Object)",
            AstType::Int => "Item data type (int)",
            AstType::SInt => "Item data type (short int)",
            AstType::KInt => "Item data type (64 bit int)",
            AstType::Byte => "Item data type (unsigned byte)",

/// A payload that is either a single value or a 1-D vector.

            Scalar1D::Scalar(_) => 0,

            Scalar1D::Scalar(v) => std::slice::from_mut(v),

    }
}
```

### Task 3: `table.rs` — hash, key comparison, key normalization, `MapSz`

Four C functions, none of which stores anything:

- `HashFun` (`keymap.c`) — djb2 over the key, skipping spaces, accumulating in an `unsigned long`, returned masked to the bucket index. Rust uses `u64` wrapping arithmetic, which matches `unsigned long` on every platform AST supports (LP64 and LLP64 both give the same masked low bits because the mask is at most 2^24).
- `KeyCmp` — `strcmp` that ignores trailing spaces. C returns `1` / `0` / `-1`; Rust returns `std::cmp::Ordering`, since `SortEntries` uses the sign and `SearchTableEntry` uses only the zero test.
- `ConvertKey` — upper-cases the key when `KeyCase` is 0, after a length check against `AST__MXKEYLEN`.

```rust
//! The parts of C's chained bucket table that a `HashMap`-backed KeyMap
//! still needs: the hash function, the trailing-space-insensitive key
//! comparison, key normalisation, and the arithmetic that reconstructs
//! the `MapSz` card at dump time.

use crate::error::{AstError, AstResult, ErrorCode};
use std::cmp::Ordering;

/// The smallest hash table C ever allocates.
pub(crate) const MIN_TABLE_SIZE: usize = 16;

/// C doubles the table when a single bucket holds more than this many
/// entries.
pub(crate) const MAX_ENTRIES_PER_TABLE_ENTRY: usize = 10;

/// `AST__MXKEYLEN`: the key buffer length used when `KeyCase` is 0.
/// The longest usable key is one character shorter, because C
/// null-terminates within the buffer.
pub(crate) const MXKEYLEN: usize = 200;

/// The used length of a string, ignoring trailing white space and
/// non-printing characters. Mirrors `astChrLen`.
pub(crate) fn chr_len(s: &str) -> usize {
    s.trim_end_matches(|c: char| !c.is_ascii_graphic() || c.is_whitespace())
        .len()
}

/// The bucket index for a key.
///
/// djb2 (`hash * 33 + c`) seeded at 5381, accumulated in an unsigned
/// 64-bit register and masked down to the table size. Spaces are ignored
/// so that trailing spaces used to pad F77 character variables will be
/// ignored.
pub(crate) fn hash_fun(key: &str, bitmask: u64) -> usize {
    let mut hash: u64 = 5381;
    for c in key.bytes() {
        if c != b' ' {
            hash = hash.wrapping_shl(5).wrapping_add(hash).wrapping_add(c as u64);
        }
    }
    (hash & bitmask) as usize
}

/// Compare two keys, ignoring trailing spaces. Mirrors `KeyCmp`, whose
/// `1` / `0` / `-1` become `Greater` / `Equal` / `Less`.
pub(crate) fn key_cmp(key1: &str, key2: &str) -> Ordering {
    let (b1, b2) = (key1.as_bytes(), key2.as_bytes());

    // Advance to the first differing byte, or to the end of the shorter
    // string.
    let mut i = 0;
    while i < b1.len() && i < b2.len() && b1[i] == b2[i] {
        i += 1;
    }

    match (i < b1.len(), i < b2.len()) {
        // Both still have characters, and they differ.
        (true, true) => b1[i].cmp(&b2[i]),
        // key2 ended: key1 matches if the rest of it is only spaces.
        (true, false) => {
            if b1[i..].iter().all(|&c| c == b' ') {
                Ordering::Equal
            } else {
                Ordering::Greater
            }
        }
        // key1 ended: mirror image.
        (false, true) => {
            if b2[i..].iter().all(|&c| c == b' ') {
                Ordering::Equal
            } else {
                Ordering::Less
            }
        }
        (false, false) => Ordering::Equal,
    }
}

/// Normalise a supplied key: when `KeyCase` is 0 the key is
/// upper-cased, and an over-long key is an error. Mirrors `ConvertKey`.
///
/// `method` is the reporting name of the calling public function, which
/// C uses verbatim in the error message.
pub(crate) fn convert_key(key: &str, key_case: bool, method: &str) -> AstResult<String> {
    if key_case {
        return Ok(key.to_string());
    }
    if chr_len(key) >= MXKEYLEN {
        return Err(AstError::new(
            ErrorCode::Bigkey,
            format!(
                "{method}(KeyMap): Supplied key '{key}' is too long (keys must be \
                 no more than {} characters long).",
                MXKEYLEN - 1
            ),
        ));
    }
    Ok(key.to_ascii_uppercase())
}

/// The table size `NewTable` allocates for a requested size: clamped up
/// to `MIN_TABLE_SIZE`, otherwise rounded up to a power of two.
pub(crate) fn new_table_size(size: usize) -> usize {
    if size <= MIN_TABLE_SIZE {
        MIN_TABLE_SIZE
    } else {
        size.next_power_of_two()
    }
}

/// The `MapSz` value to dump for a map holding `keys`.
///
/// C's `mapsize` is a running record of the collision pressure the map
/// has experienced, so it depends on the order keys were added and on
/// keys that have since been removed. This reconstructs the value a
/// freshly built C KeyMap holding exactly these keys would carry:
/// `NewTable` from `SizeGuess`, then `AddTableEntry`'s doubling rule
/// replayed over the keys in dump order.
///
/// `astMapKey`-order keys must be passed, so the result is a function of
/// the map's contents alone.
pub(crate) fn map_sz(keys: &[String], sizeguess: Option<usize>) -> usize {
    let mut mapsize = match sizeguess {
        Some(g) => new_table_size(g / MAX_ENTRIES_PER_TABLE_ENTRY),
        None => MIN_TABLE_SIZE,
    };

    let mut counts = vec![0usize; mapsize];
    let mut placed = 0usize;
    while placed < keys.len() {
        let itab = hash_fun(&keys[placed], (mapsize - 1) as u64);
        counts[itab] += 1;
        placed += 1;

        // DoubleTableSize fires when one bucket passes the limit. It
        // doubles once and redistributes, without re-checking the new
        // distribution, so a single insert never doubles twice.
        if counts[itab] > MAX_ENTRIES_PER_TABLE_ENTRY {
            mapsize *= 2;
            counts = vec![0usize; mapsize];
            for key in &keys[..placed] {
                counts[hash_fun(key, (mapsize - 1) as u64)] += 1;
            }
        }
    }

    mapsize
}
```

```c
 * a set of key populations, so the Rust MapSz arithmetic can be checked
 * against the oracle. HashFun is static, so MapSz is the observable. */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "ast.h"

static int mapsz_of(AstKeyMap *km) {
    /* Dump the KeyMap and scrape its MapSz card. */
    char *txt = astToString(km);
    int sz = -1;
    const char *p = strstr(txt, "MapSz =");
    if (p) sz = atoi(p + 7);
    txt = astFree(txt);
    return sz;
}

/* djb2 as HashFun computes it (keymap.c HashFun): start at 5381, skip
 * spaces, hash*33 + c, then mask. HashFun is static so it cannot be called
 * from here; this is the same arithmetic, used only to *choose* colliding
 * keys, never to check the port. */
static int bucket_of(const char *key, unsigned long bitmask) {
    unsigned long hash = 5381;
    for (const char *p = key; *p; p++) {
        if (*p != ' ') hash = ((hash << 5) + hash) + (unsigned char) *p;
    }
    return (int) (hash & bitmask);
}

/* The first n keys of the form K<i> that land in bucket 5 of a 16-bucket
 * table. The Rust-side colliding_keys() helper uses the same rule, so
 * neither side has to transport a key list to the other. */
static void report_colliding(const char *label, int n) {
    AstKeyMap *km = astKeyMap(" ");
    int found = 0;
    for (long i = 0; found < n; i++) {
        char key[64];
        sprintf(key, "K%ld", i);
        if (bucket_of(key, 15) == 5) {
            astMapPut0I(km, key, found, NULL);
            found++;
        }
    }
    printf("%-28s sizeguess=%-8d nkey=%-6d MapSz=%d\n",
           label, 0, n, mapsz_of(km));
    km = astAnnul(km);
}

static void report_colliding_plus_spread(const char *label, int ncoll,
                                         int nspread) {
    AstKeyMap *km = astKeyMap(" ");
    int found = 0;
    for (long i = 0; found < ncoll; i++) {
        char key[64];
        sprintf(key, "K%ld", i);
        if (bucket_of(key, 15) == 5) {
            astMapPut0I(km, key, found, NULL);
            found++;

    }

        char key[64];
        sprintf(key, "SPREAD_%d", i);
        astMapPut0I(km, key, i, NULL);
    }
    printf("%-28s sizeguess=%-8d nkey=%-6d MapSz=%d\n",
           label, 0, ncoll + nspread, mapsz_of(km));
    km = astAnnul(km);
}

                   const char *fmt) {

        sprintf(key, fmt, i);
```

### Task 5: `convert.rs` — the `ConvertValue` matrix

`ConvertValue` (`keymap.c:1655`) is a 9×9 matrix with `raw_type` on the outer branch and `out_type` on the inner one.
The whole matrix must be ported, because every `astMapGet0<X>` / `astMapGet1<X>` / `astMapGetElem<X>` call routes through it and a missing arm silently becomes "conversion impossible", which is indistinguishable from a genuine type mismatch.

The rules that are easy to get wrong, each taken directly from C:

- **`UNDEF` to `UNDEF` succeeds** and produces nothing. `UNDEF` paired with anything else fails.
- **Numeric to numeric always succeeds**, with a plain C cast — including the narrowing ones. `1000i32` to `Byte` gives `232`, not an error, because C writes `(unsigned char) ival`. Rust's `as` has the same wrapping semantics for integer narrowing, so `as` is the faithful port; do **not** use `try_into`.
- **Float to integer rounds by `+ 0.5` then truncates**, not by `round()`. The difference shows at negative half-integers: C's `(int)(-2.5 + 0.5)` is `-2`, whereas `(-2.5f64).round()` is `-3`.
- **`Double` to `String` uses a heuristic that is C's own**: format at `AST__DBL_DIG - 3` (14) and at `AST__DBL_DIG` (17) significant digits; if the full-precision form is more than 9 characters longer, use the reduced one, on the assumption that the extra characters are rounding error. C's comment says as much. `AST__BAD` formats as `"<bad>"`.
- **`Float` to `String` uses `FLT_DIG` = 6** significant digits, and has no `AST__BAD` check.
- **`String` to a numeric tries the integer form first, then the double form**, and requires the scan to consume the whole string after leading white space. `String` to `Double` additionally accepts the literal `"<bad>"` as `AST__BAD`. `String` to `Float` has **no** integer fallback — it scans `%f` only.
- **`Object` converts only to `Object`**; every other pairing fails, including `Object` to `String`.

C's `convertvalue_strings` ring buffer exists only to give the caller a pointer with a lifetime; Rust returns an owned `String`, so the ring buffer has no analogue.
C also returns `strlen + 1` rather than 1 for a successful string conversion, which `MapGet1C` ignores and `MapLenC` uses; the Rust signature returns the `String` itself, and `map_len_c` takes its length.

```rust
//! `ConvertValue`: the KeyMap type-conversion matrix.
//!
//! Every `map_get`, `map_get_1` and `map_get_elem` call routes through
//! here, so the whole 9-by-9 matrix is present. A pairing C rejects
//! returns `Ok(None)`, which callers turn into `AST__MPGER`.

use crate::constants::BAD_VALUE;
use crate::error::AstResult;
use crate::keymap::entry::{AstType, EntryValue, Scalar1D};
use crate::serial::AnyObject;
use crate::serial::native_write::format_double_g;

/// `AST__BAD_STRING`: how `AST__BAD` formats, and the only string
/// accepted as `AST__BAD` on the way back in.
pub(crate) const BAD_STRING: &str = "<bad>";

/// The number of significant digits used for a full-precision double.
/// C's `AST__DBL_DIG`.
const DBL_DIG: usize = 17;

/// `FLT_DIG`: the significant digits used for a float.
const FLT_DIG: usize = 6;

/// One value lifted out of an entry, tagged with its type.
///
/// This is what C's `void *raw` plus a separate `raw_type` amount to.
#[derive(Debug, Clone)]
pub(crate) enum RawValue {
    Int(i32),
    SInt(i16),
    KInt(i64),
    Byte(u8),
    Float(f32),
    Double(f64),
    String(String),
    /// `None` is C's NULL Object element, which `ConvertValue`'s
    /// Object-to-Object arm passes straight through (`keymap.c:2201`).
    Object(Option<Box<AnyObject>>),
    Undef,
}

impl RawValue {
    pub(crate) fn ast_type(&self) -> AstType {
        match self {
            RawValue::Int(_) => AstType::Int,
            RawValue::SInt(_) => AstType::SInt,
            RawValue::KInt(_) => AstType::KInt,
            RawValue::Byte(_) => AstType::Byte,
            RawValue::Float(_) => AstType::Float,
            RawValue::Double(_) => AstType::Double,
            RawValue::String(_) => AstType::String,
            RawValue::Object(_) => AstType::Object,
            RawValue::Undef => AstType::Undef,
        }
    }
}

/// Format a double the way `ConvertValue` does.
///
/// C formats at both `AST__DBL_DIG - 3` and `AST__DBL_DIG` significant
/// digits and keeps the reduced form when full precision costs more than
/// nine extra characters. C's own comment explains the heuristic: "If
/// reducing the number of decimal places by three produces a saving of
/// 10 or more characters, assume the least significant two characters
/// are rounding error."
pub(crate) fn double_to_string(value: f64) -> String {
    if value == BAD_VALUE {
        return BAD_STRING.to_string();
    }
    let reduced = format_double_g(value, DBL_DIG - 3);
    let full = format_double_g(value, DBL_DIG);
    if full.len() as isize - reduced.len() as isize > 9 {
        reduced
    } else {
        full
    }
}

/// Format a float the way `ConvertValue` does: `%.*g` at `FLT_DIG`
/// significant digits, with no `AST__BAD` check on this path.
pub(crate) fn float_to_string(value: f32) -> String {
    format_double_g(value as f64, FLT_DIG)
}

/// Scan a whole string as an `i64`, as C's `astSscanf( cval, " %ld %n" )`
/// followed by the "did it consume everything" test does.
fn scan_int(s: &str) -> Option<i64> {
    s.trim().parse::<i64>().ok()
}

/// Scan a whole string as an `f64`, as C's `astSscanf( cval, " %lf %n" )`
/// plus the consumed-everything test does.
fn scan_double(s: &str) -> Option<f64> {
    let t = s.trim();
    if t.is_empty() {
        return None;
    }
    t.parse::<f64>().ok()
}

/// C's `(int)( x + 0.5 )`: add a half, then truncate toward zero. This is
/// not `round()` — the two disagree for negative half-integers.
fn round_c(x: f64) -> f64 {
    (x + 0.5).trunc()
}

/// Convert `raw` to `out_type`.
///
/// `Ok(None)` is C's `result == 0`: the conversion is not possible and no
/// error is raised. The caller decides whether that is an `AST__MPGER`.
pub(crate) fn convert_value(raw: &RawValue, out_type: AstType) -> AstResult<Option<RawValue>> {
    // UNDEF pairs only with UNDEF.
    if raw.ast_type() == AstType::Undef || out_type == AstType::Undef {
        return Ok(if raw.ast_type() == AstType::Undef && out_type == AstType::Undef {
            Some(RawValue::Undef)
        } else {
            None
        });
    }

    // An Object converts only to an Object, and nothing else converts to
    // one.
    if raw.ast_type() == AstType::Object || out_type == AstType::Object {
        return Ok(match (raw, out_type) {
            (RawValue::Object(o), AstType::Object) => Some(RawValue::Object(o.clone())),
            _ => None,
        });
    }

    // From a string: scan. Every numeric target requires the scan to
    // consume the whole string.
    if let RawValue::String(s) = raw {
        return Ok(match out_type {
            AstType::String => Some(RawValue::String(s.clone())),
            AstType::Double => {
                if s.trim() == BAD_STRING {
                    Some(RawValue::Double(BAD_VALUE))
                } else {
                    scan_double(s).map(RawValue::Double)
                }
            }
            // The float path scans "%f" only: no integer-first attempt,
            // and no BAD_STRING check.
            AstType::Float => scan_double(s).map(|d| RawValue::Float(d as f32)),
            AstType::Int => scan_int(s)
                .map(|i| i as i32)
                .or_else(|| scan_double(s).map(|d| round_c(d) as i32))
                .map(RawValue::Int),
            AstType::SInt => scan_int(s)
                .map(|i| i as i16)
                .or_else(|| scan_double(s).map(|d| round_c(d) as i16))
                .map(RawValue::SInt),
            AstType::KInt => scan_int(s)
                .or_else(|| scan_double(s).map(|d| round_c(d) as i64))
                .map(RawValue::KInt),
            AstType::Byte => scan_int(s)
                .map(|i| i as u8)
                .or_else(|| scan_double(s).map(|d| round_c(d) as u8))
                .map(RawValue::Byte),
            AstType::Object | AstType::Undef => None,
        });
    }

    // Everything left is numeric to numeric or numeric to string. C uses
    // a plain cast in every numeric case, including the narrowing ones,
    // and rounds by adding a half when the source is floating point.
    let (as_i64, as_f64, is_float) = match raw {
        RawValue::Int(v) => (*v as i64, *v as f64, false),
        RawValue::SInt(v) => (*v as i64, *v as f64, false),
        RawValue::KInt(v) => (*v, *v as f64, false),
        RawValue::Byte(v) => (*v as i64, *v as f64, false),
        RawValue::Float(v) => (0, *v as f64, true),
        RawValue::Double(v) => (0, *v, true),
        RawValue::String(_) | RawValue::Object(_) | RawValue::Undef => unreachable!(),
    };
    let int_src = if is_float { round_c(as_f64) as i64 } else { as_i64 };

    Ok(Some(match out_type {
        AstType::Int => RawValue::Int(int_src as i32),
        AstType::SInt => RawValue::SInt(int_src as i16),
        AstType::KInt => RawValue::KInt(int_src),
        AstType::Byte => RawValue::Byte(int_src as u8),
        AstType::Float => RawValue::Float(as_f64 as f32),
        AstType::Double => RawValue::Double(as_f64),
        AstType::String => RawValue::String(match raw {
            RawValue::Int(v) => v.to_string(),
            RawValue::SInt(v) => v.to_string(),
            RawValue::KInt(v) => v.to_string(),
            RawValue::Byte(v) => v.to_string(),
            RawValue::Float(v) => float_to_string(*v),
            RawValue::Double(v) => double_to_string(*v),
            _ => unreachable!(),
        }),
        AstType::Object | AstType::Undef => unreachable!(),
    }))
}

/// Lift element `index` (zero-based) out of an entry.
pub(crate) fn element_at(value: &EntryValue, index: usize) -> Option<RawValue> {
    fn pick<T: Clone>(s: &Scalar1D<T>, i: usize) -> Option<T> {
        s.as_slice().get(i).cloned()
    }
    match value {
        EntryValue::Int(s) => pick(s, index).map(RawValue::Int),
        EntryValue::SInt(s) => pick(s, index).map(RawValue::SInt),
        EntryValue::KInt(s) => pick(s, index).map(RawValue::KInt),
        EntryValue::Byte(s) => pick(s, index).map(RawValue::Byte),
        EntryValue::Float(s) => pick(s, index).map(RawValue::Float),
        EntryValue::Double(s) => pick(s, index).map(RawValue::Double),
        EntryValue::String(s) => pick(s, index).map(RawValue::String),
        EntryValue::Object(s) => pick(s, index).map(RawValue::Object),
        // An undefined entry has no values, but C still lets index 0
        // through and reports the type as AST__UNDEFTYPE.
        EntryValue::Undef { .. } => {
            if index == 0 {
                Some(RawValue::Undef)
            } else {
                None
            }
        }
    }
}
```

### Task 6: `mod.rs` — the struct and the five attributes

C keeps four attributes plus `SizeGuess`, each with an out-of-band "unset" sentinel: `-1` for `keycase`, `-INT_MAX` for `keyerror` / `maplocked` / `sortby`, and `INT_MAX` for `sizeguess`.
Rust models all five as `Option`, so `is_set` is `Option::is_some` and the C `astMAKE_GET` default expression becomes `unwrap_or`.

The four defaults, from the `astMAKE_GET` block at `keymap.c:10155`:

| Attribute | Unset sentinel in C | Default when unset |
|---|---|---|
| `KeyCase` | `-1` | `1` (case sensitive) |
| `KeyError` | `-INT_MAX` | `0` |
| `MapLocked` | `-INT_MAX` | `0` |
| `SortBy` | `-INT_MAX` | `SORTBY_NONE` |
| `SizeGuess` | `INT_MAX` | `MIN_TABLE_SIZE * MAX_ENTRIES_PER_TABLE_ENTRY` = 160 |

The `SizeGuess` documentation in `keymap.c` says the default is 300; the code computes 160.
**The code is authoritative** — port 160 and do not add a comment about the discrepancy in the Rust source, because the Rust source's reader does not care about C's prose.

Setter behavior differs per attribute, and each difference is load-bearing:

- **`SizeGuess` and `KeyCase` cannot be changed once the map is non-empty.** C raises `AST__NOWRT`. `SetSizeGuess` checks unconditionally; `SetKeyCase` checks only when the value actually changes, so `set_key_case(current_value)` on a non-empty map is a permitted no-op.
- **`ClearKeyCase` restores the old value before raising**, so a failed clear leaves the attribute untouched. `ClearSizeGuess` behaves the same way.
- **`KeyError` and `MapLocked` recurse** into every nested KeyMap, scalar and vector alike. `SizeGuess`, `KeyCase` and `SortBy` do not.

### Task 7: Scalar put and get

The `MAKE_MAPPUT0` and `MAKE_MAPGET0` macro families, nine expansions each (eight in Rust: `P` is dropped).

`astMapPut0<X>` semantics, from `keymap.c:4690`:

1. Normalize the key with `ConvertKey`.
2. For the `A` variant, run `CheckCircle` first: putting a KeyMap into itself, directly or transitively, is `AST__KYCIR`.
3. Build the entry with `nel = 0` and `defined = 1`.
4. Strip trailing `' '` from the stored key — **only spaces**, unlike `astChrLen`.
5. Remove any existing entry at that key, keeping its `keymember` if there was one.
6. If the key was absent and `MapLocked` is set, fail with `AST__BADKEY` and put nothing.
7. Add the entry, bumping `member_count` **twice** for a fresh key and once for a replacement.

`astMapGet0<X>` semantics, from `keymap.c:5480`:

- A missing key returns `false`, or raises `AST__MPKER` when `KeyError` is set.
- **On a vector entry, `astMapGet0<X>` returns the first element**, because C takes `raw` as the base pointer of the vector and `ConvertValue` reads one value from it.
- An `AST__UNDEFTYPE` entry sets `raw = NULL` and returns `false` **without** consulting `KeyError`, so an undefined entry is not a missing key.
- A present-but-unconvertible value is `AST__MPGER`.

Rust returns `AstResult<Option<T>>`: `Ok(None)` is C's `result == 0` with no error, `Err` carries `AST__MPKER` or `AST__MPGER`.

The `member_count` double increment is what makes the fixture's `MemCnt = 8` correct for four keys.

```rust
    /// Store `value`, replacing any existing entry at `key`.
    ///
    /// Mirrors `astMapPut0I`. Fails with `AST__BADKEY` when `MapLocked`
    /// is set and `key` is new.
    pub fn put_0i(&mut self, key: &str, value: i32, comment: Option<&str>) -> AstResult<()> {
        self.put_scalar(key, EntryValue::Int(Scalar1D::Scalar(value)), comment, "astMapPut0I")
    }

    // … put_0s / put_0k / put_0b / put_0f / put_0d follow the same one
    // line, differing only in the EntryValue variant and the method name.

    /// Store a string, replacing any existing entry at `key`.
    /// Mirrors `astMapPut0C`.
    pub fn put_0c(&mut self, key: &str, value: &str, comment: Option<&str>) -> AstResult<()> {
        self.put_scalar(
            key,
            EntryValue::String(Scalar1D::Scalar(value.to_string())),
            comment,
            "astMapPut0C",
        )
    }

    /// Store an Object, replacing any existing entry at `key`.
    ///
    /// Mirrors `astMapPut0A`, including its `CheckCircle` guard: an
    /// Object that would make the KeyMap contain itself is `AST__KYCIR`.
    pub fn put_0a(
        &mut self,
        key: &str,
        value: AnyObject,
        comment: Option<&str>,
    ) -> AstResult<()> {
        self.check_circle(&value, "astMapPut0A")?;
        self.put_scalar(
            key,
            EntryValue::Object(Scalar1D::Scalar(Some(Box::new(value)))),
            comment,
            "astMapPut0A",
        )
    }

    fn put_scalar(
        &mut self,
        key: &str,
        value: EntryValue,
        comment: Option<&str>,
        method: &str,
    ) -> AstResult<()> {
        let key = table::convert_key(key, self.key_case(), method)?;
        self.insert_entry(key, value, comment, method)
    }

    /// Store an entry, applying C's key trimming, `MapLocked` check and
    /// age-counter rules. The key must already be normalised.
    pub(crate) fn insert_entry(
        &mut self,
        key: String,
        value: EntryValue,
        comment: Option<&str>,
        method: &str,
    ) -> AstResult<()> {
        // The put macros strip trailing spaces from the stored key. Only
        // spaces: unlike astChrLen, other white space is significant.
        let key = key.trim_end_matches(' ').to_string();

        // C removes any existing entry first, retaining its keymember so
        // the key's age survives a re-put.
        let previous = self.entries.remove(&key);

        if previous.is_none() && self.map_locked() {
            return Err(AstError::new(
                ErrorCode::Badkey,
                format!(
                    "{method}(KeyMap): Failed to add item \"{key}\" to a KeyMap: \
                     \"{key}\" is not a known item."
                ),
            ));
        }

        // AddTableEntry bumps member_count once for the entry's own
        // `member`, and a second time for a fresh key's `keymember`.
        self.member_count += 1;
        let member = self.member_count;
        let keymember = match &previous {
            Some(old) => old.keymember,
            None => {
                self.member_count += 1;
                self.member_count
            }
        };

        self.entries.insert(
            key,
            MapEntry {
                comment: comment.map(str::to_string),
                member,
                keymember,
                value,
            },
        );
        Ok(())
    }

    /// Read `key` as an `i32`. Mirrors `astMapGet0I`.
    ///
    /// `Ok(None)` means the key is absent (and `KeyError` is clear) or
    /// the entry is undefined. A present but unconvertible value is
    /// `AST__MPGER`; a missing key with `KeyError` set is `AST__MPKER`.
    pub fn get_0i(&self, key: &str) -> AstResult<Option<i32>> {
        match self.get_scalar(key, AstType::Int, "astMapGet0I")? {
            Some(RawValue::Int(v)) => Ok(Some(v)),
            _ => Ok(None),
        }
    }

    // … the other seven follow the same shape.

    fn get_scalar(
        &self,
        key: &str,
        want: AstType,
        method: &str,
    ) -> AstResult<Option<RawValue>> {
        let nkey = table::convert_key(key, self.key_case(), method)?;
        let Some(entry) = self.entries.get(nkey.trim_end_matches(' ')) else {
            if self.key_error() {
                return Err(AstError::new(
                    ErrorCode::Mpker,
                    format!(
                        "{method}(KeyMap): No value was found for {key} in the \
                         supplied KeyMap."
                    ),
                ));
            }
            return Ok(None);
        };

        // An undefined entry gives C a NULL raw pointer, which returns
        // failure without consulting KeyError: it is present, not
        // missing.
        let Some(raw) = convert::element_at(&entry.value, 0) else {
            return Ok(None);
        };

            return Ok(None);
        }

        match convert::convert_value(&raw, want)? {
            Some(v) => Ok(Some(v)),
            None => Err(AstError::new(
                ErrorCode::Mpger,
                format!(
                    "{method}(KeyMap): The value of KeyMap key \"{key}\" cannot \
                     be read using the requested data type."
                ),
            )),
        }

    /// Borrow an Object entry without copying it.
    pub(crate) fn get_object_ref(&self, key: &str) -> Option<&AnyObject> {
        let entry = self.entries.get(key.trim_end_matches(' '))?;
        match &entry.value {
            // `flatten` drops a NULL element, which is what C's
            // `aval ? astClone( aval ) : NULL` amounts to for a borrow.
            EntryValue::Object(objs) => {
                objs.as_slice().first().and_then(|b| b.as_deref())
            }
            _ => None,
        }
    }

    /// Fail with `AST__KYCIR` if storing `candidate` in this KeyMap would
    /// make the KeyMap contain itself. Mirrors `CheckCircle`.
    pub fn check_circle(&self, candidate: &AnyObject, method: &str) -> AstResult<()> {
        fn contains(haystack: &KeyMap, needle: &KeyMap) -> bool {
            if std::ptr::eq(haystack, needle) {
                return true;
            }
            for entry in haystack.entries.values() {
                if let EntryValue::Object(objs) = &entry.value {
                    for obj in objs.as_slice().iter().flatten() {
                        if let AnyObject::KeyMap(km) = obj.as_ref() {
                            if contains(km, needle) {
                                return true;
                            }
                        }
                    }
                }
            }
            false
        }

        if let AnyObject::KeyMap(km) = candidate {
            // Owned values have no identity, so the direct case is
            // detected structurally: the candidate contains an entry set
            // matching this map's own.
            if self.same_entries(km) {
                return Err(AstError::new(
                    ErrorCode::Kycir,
                    format!(
                        "{method}(KeyMap): Cannot add a KeyMap into another \
                         KeyMap because they are same KeyMap."
                    ),
                ));
            }
            if contains(km, self) {
                return Err(AstError::new(
                    ErrorCode::Kycir,
                    format!(
                        "{method}(KeyMap): Cannot add a KeyMap into another \
                         KeyMap because the first KeyMap contains the second \
                         KeyMap."
                    ),
                ));
            }
        }
        Ok(())
    }
}
```

### Task 8: Vector put and get, and per-element access

Three more macro families: `MAKE_MAPPUT1` (`keymap.c:4894`), `MAKE_MAPGET1` (`:5874`), and `MAKE_MAPPUTELEM` (`:8230`) / `MAKE_MAPGETELEM`.
Plus `astMapLength`, `astMapLenC` and `astMapGetC`, which only make sense once vectors exist.

The rules, each from C:

- **`astMapGet1<X>` truncates rather than failing** when the caller's buffer is shorter than the entry: `if( nel > mxval ) nel = mxval;`, and `*nval` reports how many were written. A scalar entry reads as a length-1 vector (`if( nel == 0 ) nel = 1;`). Rust returns `Vec<T>` sized to the entry, so the `mxval` parameter is dropped — except on `get_1c`, where the C fixed-stride buffer is observable through `map_get_c`.
- **`astMapPutElem<X>` on an absent or undefined key creates a length-1 vector** via `astMapPut1<X>( this, key, 1, &value, NULL )` — dropping any comment the entry had, because the entry is being created.
- **`astMapPutElem<X>` on a scalar promotes it to a length-1 vector**, this time **preserving** the comment (`astMapPut1##X( this, key, 1, &scalarvalue, mapentry->comment )`).
- **An out-of-range element index appends**: `new = ( elem >= nel || elem < 0 ); if( new ) { elem = nel++; … }`. A negative index appends too. Rust's `usize` cannot be negative, so only the high side is reachable, and appending is the documented behavior rather than an error.
- **`astMapGetElem<X>` does reject an out-of-range index**, with `AST__MPVIN` and the message naming the vector length. The asymmetry with put is C's.
- **`astMapLenC` returns the longest element's length**, computed as `if( --l > result ) result = l;` where `l` is `ConvertValue`'s return (string length **including** the terminator). So the reported length excludes the terminator.
- **`astMapGetC` joins a vector with `", "`** — but it reads the elements into a buffer of fixed `mxlen + 1` stride and walks that stride, so a short element is followed by the spaces padding its slot. For `["Hello", "", "Hello"]` with `mxlen` 5 this gives `"(Hello, ,  Hello)"`, length 17, which `testkeymap.c` asserts. This is C's behavior, not a bug to fix.
- `astMapGetC` on a length-0 entry returns failure; on a length-1 entry it delegates to `astMapGet0C` with no parentheses.

```rust
fn get_vector(
    &self,
    key: &str,
    want: AstType,
    method: &str,
) -> AstResult<Option<Vec<RawValue>>> {
    let nkey = table::convert_key(key, self.key_case(), method)?;
    let Some(entry) = self.entries.get(nkey.trim_end_matches(' ')) else {
        if self.key_error() {
            return Err(AstError::new(
                ErrorCode::Mpker,
                format!(
                    "{method}(KeyMap): No value was found for {key} in the \
                     supplied KeyMap."
                ),
            ));
        }
        return Ok(None);
    };
    if !entry.value.defined() {
        return Ok(None);
    }

    // C reads `nel` values, treating a scalar as one.
    let n = entry.value.len().max(1);
    let mut out = Vec::with_capacity(n);
    for i in 0..n {
        let Some(raw) = convert::element_at(&entry.value, i) else {
            break;
        };
        match convert::convert_value(&raw, want)? {
            Some(v) => out.push(v),
            None => {
                return Err(AstError::new(
                    ErrorCode::Mpger,
                    format!(
                        "{method}(KeyMap): The value of element {} of KeyMap key \
                         \"{key}\" cannot be read using the requested data type.",
                        i + 1
                    ),
                ));
            }
        }
    }
    Ok(Some(out))
}
```

```rust
fn put_elem(
    &mut self,
    key: &str,
    elem: usize,
    value: RawValue,
    method: &str,
) -> AstResult<()> {
    let nkey = table::convert_key(key, self.key_case(), method)?;
    let nkey = nkey.trim_end_matches(' ').to_string();

    // An absent or undefined entry is created as a length-1 vector, with
    // no comment: C calls astMapPut1<X> with a NULL comment.
    let existing = self.entries.get(&nkey);
    let needs_create = match existing {
        None => true,
        Some(e) => !e.value.defined(),
    };
    if needs_create {
        let value = single_element_vector(&value);
        return self.insert_entry(nkey, value, None, method);
    }

    // A scalar is promoted to a length-1 vector, keeping its comment.
    let entry = self.entries.get_mut(&nkey).expect("checked above");
    if entry.value.nel() == 0 {
        promote_scalar_to_vector(&mut entry.value);
    }

    let want = entry.value.ast_type();
    let Some(converted) = convert::convert_value(&value, want)? else {
        return Err(AstError::new(
            ErrorCode::Mpper,
            format!(
                "{method}(KeyMap): The supplied value cannot be converted to \
                 the data type of KeyMap key \"{key}\"."
            ),
        ));
    };

    // An index at or beyond the end appends, rather than failing.
    let n = entry.value.len();
    let target = if elem >= n { n } else { elem };
    set_element(&mut entry.value, target, converted);

    // The put counts as a value put, so `member` advances but the key's
    // `keymember` does not.
    self.member_count += 1;
    self.entries
        .get_mut(&nkey)
        .expect("checked above")
        .member = self.member_count;
    Ok(())
}
```

```rust
/// The number of values held at `key`: 0 if the key is absent, 1 for a
/// scalar, the vector length otherwise. Mirrors `astMapLength`, which
/// has no `KeyError` branch.
pub fn map_length(&self, key: &str) -> usize {
    match self.lookup(key) {
        Some(entry) => entry.value.len().max(1),
        None => 0,
    }
}

/// The length of the longest value at `key` when formatted as a string,
/// excluding the terminating null C counts. Mirrors `astMapLenC`.
pub fn map_len_c(&self, key: &str) -> AstResult<usize> {
    let Some(entry) = self.lookup(key) else {
        return Ok(0);
    };
    let mut result = 0;
    for i in 0..entry.value.len().max(1) {
        let Some(raw) = convert::element_at(&entry.value, i) else {
            break;
        };
        if let Some(RawValue::String(s)) = convert::convert_value(&raw, AstType::String)? {
            result = result.max(s.len());
        }
    }
    Ok(result)
}

/// The value at `key` formatted as a single string. A vector is joined
/// with ", " inside parentheses. Mirrors `astMapGetC`.
///
/// C reads the elements into a buffer whose stride is the longest
/// element's length plus one, and walks that stride, so a short element
/// is followed by the spaces padding its slot. The joined form of
/// `["Hello", "", "Hello"]` is therefore `"(Hello, ,  Hello)"`.
pub fn map_get_c(&self, key: &str) -> AstResult<Option<String>> {
    let nval = self.map_length(key);
    if nval == 0 {
        return Ok(None);
    }
    if nval == 1 {
        return self.get_0c(key);
    }
    let mxlen = self.map_len_c(key)?;
    let Some(parts) = self.get_1c(key)? else {
        return Ok(None);
    };
    let mut out = String::from("(");
    for (i, part) in parts.iter().enumerate() {
        if i > 0 {
            out.push_str(", ");
        }
        // The element occupies a fixed mxlen+1 slot; the unused tail is
        // spaces, and C copies the whole slot.
        out.push_str(part);
        out.push_str(&" ".repeat(mxlen - part.len()));
    }
    out.push(')');
    Ok(Some(out))
}
```

### Task 9: Key-level methods

`astMapPutU` (`keymap.c:5147`), `astMapType` (`:8496`), `astMapHasKey` (`:7448`), `astMapDefined` (`:7347`), `astMapRemove` (`:7545`), `astMapRename` (`:7608`), `astMapSize` (`:7747`), `astMapKey` (`:4432` via `GetKey` at `:3430`) and `astMapIterate` (`:8599`).

`map_key` and `map_iterate` need an ordered read-out, which is Task 10's job.
This task implements them against a `sorted_keys()` helper that, for now, returns keys in `key_cmp` order regardless of `SortBy`; Task 10 replaces the body and both methods pick up the other six modes with no further change.

The rules, each from C:

- **`astMapPutU` stores an entry with `AST__UNDEFTYPE` and `defined = 0`.** It takes a comment, is subject to `MapLocked` exactly as a put is, and reuses the previous `keymember` when replacing.
- **`astMapType` returns `AST__BADTYPE` for a missing key**, never an error, and never consults `KeyError`.
- **`astMapHasKey` is true for an undefined entry; `astMapDefined` is not.** Neither consults `KeyError`.
- **`astMapRemove` on a missing key is silent.** `RemoveTableEntry` returns NULL and `FreeMapEntry(NULL)` is a no-op.
- **`astMapRename` is a no-op when the two normalized keys are equal** (`if( strcmp( oldkey, newkey ) )` guards the whole body), and silently does nothing when the old key is absent.
- **`astMapRename` inherits the destination's `keymember` when the destination already existed**, and allocates a fresh one otherwise — the same `keymember >= 0 ? reuse : allocate` rule `AddTableEntry` applies. So renaming onto an occupied key keeps that key's age, and renaming onto a free key makes the entry the newest key.
- **`astMapRename` respects `MapLocked`**: renaming onto a key that does not already exist in a locked KeyMap raises `AST__BADKEY`. C's message names the *new* key twice.
- **`astMapRename` re-normalizes the new key**, stripping trailing `' '` in place exactly as the put macros do.
- **`astMapKey` reports `AST__MPIND` for an out-of-range index** — `GetKey`'s tail, not a silent `None`.
- **`astMapIterate`'s `reset` flag drives a stored cursor.** Rust holds the cursor as a `usize` index into the ordered key list, which is what makes Bug 3 unexpressible.

`map_comment` has no C counterpart: C exposes an entry's comment only through the dump.
Rust adds it because `to_node` needs it and because a caller who can set a comment should be able to read it back.
Document it as a Rust addition in its doc comment; do not present it as a port of anything.

```rust
/// Move the entry at `old_key` to `new_key`, replacing any entry already
/// there. Mirrors `astMapRename`.
pub fn map_rename(&mut self, old_key: &str, new_key: &str) -> AstResult<()> {
    let old = table::convert_key(old_key, self.key_case(), "astMapRename")?;
    let new = table::convert_key(new_key, self.key_case(), "astMapRename")?;
    let old = old.trim_end_matches(' ').to_string();
    let new = new.trim_end_matches(' ').to_string();

    // C guards its entire body on the two keys differing.
    if old == new {
        return Ok(());
    }

    // Renaming an absent key is silently ignored: C's RemoveTableEntry
    // returns NULL and the body is skipped.
    let Some(mut entry) = self.entries.remove(&old) else {
        return Ok(());
    };

    // The destination's key age is inherited if it was occupied; a fresh
    // one is allocated if it was not. This is AddTableEntry's rule.
    let previous = self.entries.remove(&new);
    let there = previous.is_some();

    if !there && self.map_locked() {
        // C leaves the old entry removed and the new one unwritten. Put
        // the entry back so the KeyMap is unchanged by the failure.
        self.entries.insert(old, entry);
        return Err(AstError::new(
            ErrorCode::Badkey,
            format!(
                "astMapRename(KeyMap): Failed to rename item \"{old_key}\" in \
                 a KeyMap to \"{new_key}\": \"{new_key}\" is not a known item."
            ),
        ));
    }

    self.member_count += 1;
    entry.member = self.member_count;
    entry.keymember = match previous {
        Some(old_dest) => old_dest.keymember,
        None => {
            self.member_count += 1;
            self.member_count
        }
    };
    self.entries.insert(new, entry);
    Ok(())
}
```

C does *not* restore the removed entry when the locked check fails — it leaves the KeyMap with the old key gone and the new key absent, losing the entry.

### Task 10: `sort.rs` — the seven `SortBy` modes

`CompareEntries` (`keymap.c:1463`), `SortByInt` (`:9666`) and `SortByString` (`:9742`).
This replaces Task 9's placeholder `sorted_keys` body, and both `map_key` and `map_iterate` pick up all seven modes with no edit.

The rules, each from C:

- **The integer codes are load-bearing** because they appear in no dump — the dump writes the *string* (`astWriteString( channel, "SortBy", … SortByString( ival … ) )` at `:10486`).
  But `SortByInt`/`SortByString` must round-trip, and the codes matter for the `TestSortBy` comparison against the `-INT_MAX` unset sentinel.
  They are `SORTBY_NONE 0`, `AGEUP 1`, `AGEDOWN 2`, `KEYUP 3`, `KEYDOWN 4`, `KEYAGEUP 5`, `KEYAGEDOWN 6` (`:239-245`).
- **"Up" means newest first.** `SORTBY_AGEUP` returns `1` when `first->member < second->member`, so a *lower* member index — an *older* entry — sorts *later*.
  The name reads backwards; follow the code.
  `AgeDown` and `KeyAgeDown` are the reverse, putting the oldest first.
- **`KeyUp` is `KeyCmp(first, second)`; `KeyDown` is `KeyCmp(second, first)`** — argument order, not negation. For `KeyCmp` these coincide, but write it C's way.
- **`SORTBY_NONE` reaches `CompareEntries` with `result` still 0**, so under C every entry compares equal and `qsort` leaves them in whatever order the array was built in. Rust sorts by `key_cmp` instead; that is the intentional divergence already recorded in the quirks doc.
- **`SortByInt` uses `astChrMatch`**, which folds case *and* tolerates trailing whitespace on either side. So `"keyup"`, `"KEYUP  "` and `"KeyUp"` all parse.
- **An unrecognized string is `AST__INTER`**, not a user error: `"%s(KeyMap): Illegal SortBy value %s encountered."` — note the absence of the "(internal AST programming error)" tail that `SortByString`'s message has.
- **`SortBy` is not applied at dump time.** `Dump` (`:10460`) walks the hash table directly and never consults `SortBy`, so Task 12's `to_node` must use `key_cmp` order unconditionally, *not* `sorted_keys()`.

```rust
//! Key ordering for a `KeyMap`.
//!
//! Ported from `CompareEntries`, `SortByInt` and `SortByString` in
//! `reference/starlink-ast/src/keymap.c`.

use std::cmp::Ordering;

use crate::error::{AstError, AstResult, ErrorCode};
use crate::keymap::entry::MapEntry;
use crate::keymap::table;

/// How the entries of a `KeyMap` are ordered when read out.
///
/// "Up" orders the newest entry first; "Down" orders the oldest first.
/// The `Age` variants track the age of the *value*, which a re-put
/// advances, and the `KeyAge` variants the age of the *key*, which it does
/// not.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum SortBy {
    /// No sorting requested. Keys are read out in alphabetical order.
    #[default]
    None,
    /// Newest value first.
    AgeUp,
    /// Oldest value first.
    AgeDown,
    /// Alphabetically ascending.
    KeyUp,
    /// Alphabetically descending.
    KeyDown,
    /// Newest key first.
    KeyAgeUp,
    /// Oldest key first.
    KeyAgeDown,
}

impl SortBy {
    /// The integer code C uses for this value (`keymap.c:239`).
    pub fn code(self) -> i32 {
        match self {
            SortBy::None => 0,
            SortBy::AgeUp => 1,
            SortBy::AgeDown => 2,
            SortBy::KeyUp => 3,
            SortBy::KeyDown => 4,
            SortBy::KeyAgeUp => 5,
            SortBy::KeyAgeDown => 6,
        }
    }

    /// The value with the given integer code, or `None` if the code is not
    /// one C defines.
    pub fn from_code(code: i32) -> Option<Self> {
        Some(match code {
            0 => SortBy::None,
            1 => SortBy::AgeUp,
            2 => SortBy::AgeDown,
            3 => SortBy::KeyUp,
            4 => SortBy::KeyDown,
            5 => SortBy::KeyAgeUp,
            6 => SortBy::KeyAgeDown,
            _ => return None,
        })
    }

    /// The string form written to a dump. Mirrors `SortByString`.
    pub fn as_str(self) -> &'static str {
        match self {
            SortBy::None => "None",
            SortBy::AgeUp => "AgeUp",
            SortBy::AgeDown => "AgeDown",
            SortBy::KeyUp => "KeyUp",
            SortBy::KeyDown => "KeyDown",
            SortBy::KeyAgeUp => "KeyAgeUp",
            SortBy::KeyAgeDown => "KeyAgeDown",
        }
    }

    /// Parse a string form. Mirrors `SortByInt`, which compares with
    /// `astChrMatch`: case is folded and trailing whitespace on either side
    /// is ignored.
    pub fn parse(text: &str) -> AstResult<Self> {
        let trimmed = text.trim_end();
        for candidate in [
            SortBy::None,
            SortBy::AgeUp,
            SortBy::AgeDown,
            SortBy::KeyAgeUp,
            SortBy::KeyAgeDown,
            SortBy::KeyUp,
            SortBy::KeyDown,
        ] {
            if trimmed.eq_ignore_ascii_case(candidate.as_str()) {
                return Ok(candidate);
            }
        }
        Err(AstError::new(
            ErrorCode::Inter,
            format!("SortBy(KeyMap): Illegal SortBy value {text} encountered."),
        ))
    }
}

/// Order two entries under `sort_by`. Mirrors `CompareEntries`, except
/// that `SortBy::None` orders by key rather than leaving the pair equal;
/// see `docs/issues/c-library-quirks.md`.
pub(crate) fn compare_entries(
    sort_by: SortBy,
    a: (&str, &MapEntry),
    b: (&str, &MapEntry),
) -> Ordering {
    let (key_a, ent_a) = a;
    let (key_b, ent_b) = b;
    match sort_by {
        // Newest first, so the comparison is reversed relative to the
        // counter.
        SortBy::AgeUp => ent_b.member.cmp(&ent_a.member),
        SortBy::AgeDown => ent_a.member.cmp(&ent_b.member),
        SortBy::KeyAgeUp => ent_b.keymember.cmp(&ent_a.keymember),
        SortBy::KeyAgeDown => ent_a.keymember.cmp(&ent_b.keymember),
        SortBy::KeyUp | SortBy::None => table::key_cmp(key_a, key_b),
        SortBy::KeyDown => table::key_cmp(key_b, key_a),
    }
}
```

```rust
/// `SortBy::None` orders alphabetically. C leaves it unordered, reading

    let sort_by = self.sort_by();
    let mut keys: Vec<&String> = self.entries.keys().collect();
    keys.sort_by(|a, b| {
        sort::compare_entries(
            sort_by,
            (a.as_str(), &self.entries[*a]),
            (b.as_str(), &self.entries[*b]),
        )
    });
    keys.into_iter().cloned().collect()
}
```

`sort_by` never produces `Ordering::Equal` for two distinct keys under the `KeyUp`/`KeyDown`/`None` modes, and the member counters are unique per entry, so the sort is total and `sort_by` rather than `sort_unstable_by` is not required for determinism.
Use `sort_by` anyway: it costs nothing here and it removes the question.

### Task 11: `map_copy` and `map_copy_entry`

`MapCopy` (`keymap.c:4112`) and `MapCopyEntry` (`:4264`).
They share their whole body bar one flag, so port the shared part once.

The rules, each from C:

- **A source key absent from the destination is added; a locked destination refuses it** with `AST__BADKEY` and the message `"astMapCopy(%s): Failed to copy item \"%s\": \"%s\" is not a known item."` — the key appears twice, and `astMapCopyEntry` uses its own method name in the same text.
- **A source key present in the destination replaces the destination's value but keeps its `keymember`**, so the copied-over key keeps its position under `KeyAgeUp`/`KeyAgeDown`.
- **The one exception is nested KeyMaps: they merge rather than replace.** If both entries are `AST__OBJECTTYPE`, both have `nel == 0 || nel == 1`, and both objects are KeyMaps, C recurses `astMapCopy` into the destination's nested KeyMap instead of overwriting it. `astMapCopyEntry` does this only when its `merge` argument is non-zero; `astMapCopy` always does.
- **`nel == 1` counts as scalar for the merge test.** A length-1 vector of KeyMaps merges through its element 0, not through replacement. Note that only element 0 participates: a length-1 vector is the only vector case, since `nel >= 2` fails the test.
- **The recursion is into the destination's *existing* nested KeyMap object**, so its own `MapLocked`, `KeyCase` and other attributes govern the merge, not the outer destination's.
- **`astMapCopyEntry` normalizes the key using the *source*'s `KeyCase`** (`ConvertKey( that, skey, … )`), then uses that same string to look up the destination. If the two KeyMaps have different `KeyCase` settings, the destination lookup uses the wrong casing. Mirror this — it is C's behavior, and a caller with mismatched `KeyCase` on two KeyMaps has already left well-defined territory. Record it as a sixth section in `docs/issues/c-library-quirks.md`: `### astMapCopyEntry normalises the key with the source KeyMap's KeyCase`, citing `keymap.c:4350`.
- **A source key absent from the source is silently ignored** by `astMapCopyEntry` (`if( in_entry )` guards the body).
- **C copies in source bucket order**, which sets the order in which fresh destination keys get their `member`/`keymember` counters. Rust copies in `key_cmp` order, so the counters differ from C's for keys added by the copy. This follows from the ordering decision already taken and needs no separate quirks entry; the existing `:1416` section covers it.

```rust
/// Copy every entry from `source` into this KeyMap. Mirrors `astMapCopy`.
///
/// An entry whose key already exists here is replaced, keeping this
/// KeyMap's record of when the key was first added. The exception is a
/// nested scalar KeyMap on both sides, which is merged recursively rather
/// than replaced. A key that does not already exist is an error when
/// `MapLocked` is set.
pub fn map_copy(&mut self, source: &KeyMap) -> AstResult<()> {
    for key in source.sorted_keys() {
        self.copy_one(&key, source, true, "astMapCopy")?;
    }
    Ok(())
}

/// Copy the single entry `key` from `source` into this KeyMap. Mirrors
/// `astMapCopyEntry`.
///
/// `merge` selects whether a nested scalar KeyMap present on both sides is
/// merged recursively or replaced outright. A key absent from `source` is
/// silently ignored.
pub fn map_copy_entry(
    &mut self,
    key: &str,
    source: &KeyMap,
    merge: bool,
) -> AstResult<()> {
    // C normalises the key with the *source* KeyMap's KeyCase, then uses
    // the result to look up both KeyMaps.
    let nkey = table::convert_key(key, source.key_case(), "astMapCopyEntry")?;
    let nkey = nkey.trim_end_matches(' ').to_string();
    if !source.entries.contains_key(&nkey) {
        return Ok(());
    }
    self.copy_one(&nkey, source, merge, "astMapCopyEntry")
}

/// The body `map_copy` and `map_copy_entry` share. `key` is already
/// normalised.
fn copy_one(
    &mut self,
    key: &str,
    source: &KeyMap,
    merge: bool,
    method: &str,
) -> AstResult<()> {
    let in_entry = source.entries.get(key).expect("caller checked presence");

    let Some(out_entry) = self.entries.get_mut(key) else {
        if self.map_locked() {
            return Err(AstError::new(
                ErrorCode::Badkey,
                format!(
                    "{method}(KeyMap): Failed to copy item \"{key}\": \
                     \"{key}\" is not a known item."
                ),
            ));
        }
        let copied = in_entry.clone();
        return self.insert_entry_raw(key.to_string(), copied, None, method);
    };

    // Two nested scalar KeyMaps merge rather than replace. C accepts nel 0
    // or 1 on both sides, so a length-1 vector merges through element 0.
    if merge
        && let Some(inner_src) = single_key_map(&in_entry.value)
        && let Some(inner_dest) = single_key_map_mut(&mut out_entry.value)
    {
        return inner_dest.map_copy(inner_src);
    }

    // Otherwise replace the value while keeping the key's own age.
    let keymember = out_entry.keymember;
    let mut copied = in_entry.clone();
    self.member_count += 1;
    copied.member = self.member_count;
    copied.keymember = keymember;
    self.entries.insert(key.to_string(), copied);
    Ok(())
}
```

`insert_entry_raw` is `insert_entry` split so that a pre-built `MapEntry` can be inserted without re-deriving its value: factor `insert_entry` in Task 7 into a thin wrapper over it. `insert_entry_raw` still assigns fresh `member`/`keymember` counters, which is what `AddTableEntry( …, -1, … )` does for a brand-new key.

The two helpers go in `entry.rs`:

```rust
        EntryValue::Object(Scalar1D::Scalar(obj)) => obj.as_deref()?,
```

### Task 12: `serial.rs` — `to_node` and `from_node`

`Dump` (`keymap.c:10460`), `DumpEntry` (`:2700`) and `astLoadKeyMap` (`:10844`).

The card order, from `Dump`:

1. `SzGss`, `SortBy`, `KyCas`, `KyErr`, `MpLck` — each written with `set` as its "is set" flag and `0` as its "helpful" flag, so an unset attribute is written commented out.
2. `MapSz` and `MemCnt` — both written with `1, 1`, so unconditional and never commented.
3. Then each entry in turn via `DumpEntry`, numbered from 1.

The class comment is `"Map of key/value pairs"` (`keymap.c:3848`).
There is no `IsA` marker: `KeyMap` derives directly from `Object`, and the fixture confirms the dump goes straight from `MemCnt` to `Key1`.

`DumpEntry`'s card order per entry `n`:

- `Key%d` — the key, comment `"Item name"`.
- `Com%d` — only when the comment is present *and* non-empty (`entry->comment && *(entry->comment)`), comment `"Item comment"`.
- `Typ%d` — the numeric type code, with the per-type comment from `AstType::type_comment` (Task 2).
- `Nel%d` — only when `nel > 0`, comment `"Vector length"`.
- `Val%d` for a scalar, comment `"Item value"`; or `V%d_%d` per element with `index + 1`, comment `"Item values"` on the first element and `""` — an empty comment, not an absent one — on the rest.

Four per-type rules inside `DumpEntry`:

- **A `BAD_VALUE` double is omitted entirely** — no `Val%d` card at all for a scalar, and no `V%d_%d` card for that element of a vector. The `com` rotation happens inside the `if`, so if element 0 is bad, `"Item values"` lands on the first *written* element instead.
- **A float is written through `astWriteDouble`**, so a `f32` is widened and formatted as a double. There is no BAD check on the float path.
- **`AST__SINTTYPE` and `AST__BYTETYPE` are written through `astWriteInt`** after a cast, so both appear as plain integers. `AST__KINTTYPE` uses `astWriteInt64`.
- **A null Object is omitted**, exactly as a BAD double is. This branch is *reachable*: `MapPut1A` stores `(value[i]?astClone(value[i]):NULL)` (`keymap.c:5012`), `MapPut0A` the same (`:4773`), and `CopyMapEntry` propagates it (`:2404`), so an Object entry — scalar or vector — can legitimately hold a null. `testkeymap.c` relies on it, storing `avec = { SkyFrame, NULL, SpecFrame, NULL }` and asserting the two nulls read back as null. So `EntryValue::Object` holds `Option<AnyObject>` / `Scalar1D<Option<AnyObject>>`, and a null element writes no card, just as a BAD double does.

`astLoadKeyMap`'s read order and its four traps:

- **Each attribute is read into the field and then passed through its own setter if the test predicate says it was set** — `new->sizeguess = astReadInt(…); if( TestSizeGuess(…) ) SetSizeGuess(…)`. That matters for `SizeGuess`, whose setter refuses on a non-empty map: the read happens before any entry is loaded, so the refusal never fires.
- **`SortBy` is read as a *string*, defaulting to `" "`**, and only parsed when it differs from `" "`. So an absent `SortBy` card leaves the attribute unset, not `None`.
- **`MapSz` defaults to `MIN_TABLE_SIZE`** and is fed straight to `NewTable`. Rust reads it and discards it: the value is C's bucket-count history and has no `HashMap` counterpart. Task 17 excludes it from the byte-exact comparison for the same reason.
- **`mem%d` is read but never written.** `LoadKeyMap` does `new->member_count = astReadInt( channel, buff, 0 )` per entry (`:11067`) but `DumpEntry` emits no `Mem%d` card anywhere. So on every real load the value defaults to 0, resetting `member_count` before each entry, and the final `memcnt` read (`:11175`) overwrites the accumulated total anyway. Rust reads `MemCnt` into `member_count` after loading the entries and ignores `Mem%d` entirely, which is what C effectively does. Record this as a seventh section in `docs/issues/c-library-quirks.md`: `### LoadKeyMap reads a Mem%d card that DumpEntry never writes`, citing `keymap.c:11067` against `:2700-2930`, and noting that the per-entry member numbers are therefore not preserved across a dump/load cycle — only the total is.
- **Loading uses the public put path**, so `MapLocked` and `KeyCase` are applied to the loaded keys. Since `KyCas` is read before the entries, a `KyCas = 0` dump reloads with its keys uppercased. Match this by loading through `put_*`.
- **An unknown type code is `AST__BDFTS`**: `"astLoadKeyMap(%s): Unknown data type code (%d) encountered whilst reading a %s."` A *missing* `Typ%d` card is a different error with the same code: `"astLoadKeyMap(%s): No data type code found whilst reading a %s."`
- **The entry loop stops at the first missing `Key%d`**, so a gap in the numbering silently truncates. Preserve that.
- **Per-element defaults differ by type**: int-family and float default to 0, double defaults to `AST__BAD` (so an omitted `V%d_%d` reads back as BAD, which is what round-trips the omitted-BAD dump rule), string defaults to `""`, Object to null.

```rust
//! Native-format serialisation for `KeyMap`.
//!
//! Ported from `Dump`, `DumpEntry` and `astLoadKeyMap` in
//! `reference/starlink-ast/src/keymap.c`.

use crate::constants::BAD_VALUE;
use crate::error::{AstError, AstResult, ErrorCode};
use crate::keymap::entry::{AstType, EntryValue, Scalar1D};
use crate::keymap::sort::SortBy;
use crate::keymap::{table, KeyMap};
use crate::serial::node::{Node, NodeValue};
use crate::serial::Serializable;

impl Serializable for KeyMap {
    fn class_name(&self) -> &'static str {
        "KeyMap"
    }

    fn to_node(&self) -> AstResult<Node> {
        let mut node = Node::new("KeyMap");
        node.class_comment = Some("Map of key/value pairs".to_string());

        // The five attributes, each commented out when unset.
        push_int_attr(
            &mut node,
            "SzGss",
            self.size_guess() as i64,
            self.test_size_guess(),
            "Guess at KeyMap size",
        );
        push_string_attr(
            &mut node,
            "SortBy",
            self.sort_by().as_str(),
            self.test_sort_by(),
            "Sorting scheme for keys",
        );
        push_int_attr(
            &mut node,
            "KyCas",
            self.key_case() as i64,
            self.test_key_case(),
            "Are keys case sensitive?",
        );
        push_int_attr(
            &mut node,
            "KyErr",
            self.key_error() as i64,
            self.test_key_error(),
            "Report non-existant keys?",
        );
        push_int_attr(
            &mut node,
            "MpLck",
            self.map_locked() as i64,
            self.test_map_locked(),
            "Prevent addition of new entries?",
        );

        // Both unconditional in C.
        node.push_int(
            "MapSz",
            self.map_sz_for_dump(),
            Some("Size of hash table".to_string()),
        );
        node.push_int(
            "MemCnt",
            self.member_count as i64,
            Some("Total member count".to_string()),
        );

        for (n, key) in self.dump_keys().into_iter().enumerate() {
            let entry = &self.entries[&key];
            dump_entry(&mut node, n + 1, &key, entry)?;
        }
        Ok(node)
    }

    fn from_node(node: &Node) -> AstResult<Self> {
        let mut km = KeyMap::new();

        // C reads each attribute before any entry, and applies it through
        // its own setter. SizeGuess and KeyCase refuse on a non-empty map,
        // which is why the read has to happen first.
        if let Some(v) = node.get_int_any_if_set("SzGss") {
            km.set_size_guess(v as usize)?;
        }
        if let Some(v) = node.get_string_if_set("SortBy") {
            km.set_sort_by(SortBy::parse(&v)?);
        }
        if let Some(v) = node.get_int_any_if_set("KyCas") {
            km.set_key_case(v != 0)?;
        }
        if let Some(v) = node.get_int_any_if_set("KyErr") {
            km.set_key_error(v != 0);
        }
        if let Some(v) = node.get_int_any_if_set("MpLck") {
            km.set_map_locked(v != 0);
        }

        // MapSz is C's bucket-count history and has no HashMap counterpart,
        // so it is read and discarded. The written value is recomputed from
        // the contents at dump time.

        // Presize from the number of Key%d cards present.
        let n_entries = node
            .items
            .iter()
            .filter(|i| {
                i.key.len() > 3
                    && i.key[..3].eq_ignore_ascii_case("key")
                    && i.key[3..].chars().all(|c| c.is_ascii_digit())
            })
            .count();
        km.entries.reserve(n_entries);

        let mut n = 0;
        loop {
            n += 1;
            // The loop stops at the first missing key, so a gap in the
            // numbering truncates the load.
            let Some(key) = node.get_string_if_set(&format!("Key{n}")) else {
                break;
            };
            let comment = node.get_string_if_set(&format!("Com{n}"));
            load_entry(&mut km, node, n, &key, comment.as_deref())?;
        }

        // The final total, which C reads after the entries so it overrides
        // whatever the puts accumulated.
        km.member_count = node.get_int("MemCnt", 0) as i32;
        Ok(km)
    }
}
```

`dump_keys` is `sorted_keys` with `SortBy` forced to `None` — `Dump` never consults `SortBy`, so the dump order is always `key_cmp`:

```rust
/// The keys in dump order, which is always `key_cmp` order.
///
/// `Dump` walks the hash table directly and never consults `SortBy`, so
/// the dump order is independent of the read-out order.
pub(crate) fn dump_keys(&self) -> Vec<String> {
    let mut keys: Vec<String> = self.entries.keys().cloned().collect();
    keys.sort_by(|a, b| table::key_cmp(a, b));
    keys
}

/// The `MapSz` value to write, replayed from the contents in dump order.
pub(crate) fn map_sz_for_dump(&self) -> i64 {
    table::map_sz(&self.dump_keys(), self.size_guess()) as i64
}
```

`dump_entry` walks the card sequence:

```rust
fn dump_entry(
    node: &mut Node,
    n: usize,
    key: &str,
    entry: &MapEntry,
) -> AstResult<()> {
    node.push_string(&format!("Key{n}"), key, Some("Item name".to_string()));

    // C tests both the pointer and the first character, so an empty
    // comment is not written.
    if let Some(comment) = &entry.comment {
        if !comment.is_empty() {
            node.push_string(
                &format!("Com{n}"),
                comment,
                Some("Item comment".to_string()),
            );
        }
    }

    let ast_type = entry.value.ast_type();
    node.push_int(
        &format!("Typ{n}"),
        ast_type.code() as i64,
        Some(ast_type.type_comment().to_string()),
    );

    let nel = entry.value.nel();
    if nel > 0 {
        node.push_int(
            &format!("Nel{n}"),
            nel as i64,
            Some("Vector length".to_string()),
        );
    }

    // The comment goes on the first element actually written, and an empty
    // string on the rest.
    let mut com: Option<&str> = Some("Item values");
    let scalar_name = format!("Val{n}");
    for i in 0..entry.value.len().max(1) {
        let name = if nel == 0 {
            scalar_name.clone()
        } else {
            format!("V{n}_{}", i + 1)
        };
        let comment = if nel == 0 {
            Some("Item value".to_string())
        } else {
            Some(com.unwrap_or("").to_string())
        };
        if push_element(node, &name, comment, &entry.value, i)? && nel > 0 {
            com = None;
        }
    }
    Ok(())
}
```

`push_element` returns whether it wrote a card, and holds the four per-type rules:

```rust
/// Write element `i` of `value` as a card, returning whether anything was
/// written. A `BAD_VALUE` double writes nothing, matching `DumpEntry`.
fn push_element(
    node: &mut Node,
    name: &str,
    comment: Option<String>,
    value: &EntryValue,
    i: usize,
) -> AstResult<bool> {
    match value {
        // Short and byte go through astWriteInt after a cast, so both
        // appear as plain integers.
        EntryValue::Int(v) => node.push_int(name, element(v, i) as i64, comment),
        EntryValue::Short(v) => node.push_int(name, element(v, i) as i64, comment),
        EntryValue::Byte(v) => node.push_int(name, element(v, i) as i64, comment),
        EntryValue::Long(v) => node.push_int(name, element(v, i), comment),
        EntryValue::Double(v) => {
            let d = element(v, i);
            if d == BAD_VALUE {
                return Ok(false);
            }
            node.push_double(name, d, comment);
        }
        // A float is widened and written as a double, with no BAD check.
        EntryValue::Float(v) => node.push_double(name, element(v, i) as f64, comment),
        EntryValue::String(v) => node.push_string(name, &element_ref(v, i), comment),
        EntryValue::Object(v) => {
            // A null Object element writes no card, exactly as a BAD
            // double does.
            let Some(obj) = element_ref(v, i).as_deref() else {
                return Ok(false);
            };
            node.push_object(name, obj.to_node()?, comment);
        }
        // An undefined entry has nothing after its Typ card.
        EntryValue::Undef { .. } => return Ok(false),
    }
    Ok(true)
}
```

```rust
fn load_entry(
    km: &mut KeyMap,
    node: &Node,
    n: usize,
    key: &str,
    comment: Option<&str>,
) -> AstResult<()> {
    let code = node.get_int_any(&format!("Typ{n}")).ok_or_else(|| {
        AstError::new(
            ErrorCode::Bdfts,
            "astLoadKeyMap(KeyMap): No data type code found whilst reading a \
             KeyMap."
                .to_string(),
        )
    })? as i32;
    let ast_type = AstType::from_code(code).ok_or_else(|| {
        AstError::new(
            ErrorCode::Bdfts,
            format!(
                "astLoadKeyMap(KeyMap): Unknown data type code ({code}) \
                 encountered whilst reading a KeyMap."
            ),
        )
    })?;

    let nel = node.get_int(&format!("Nel{n}"), 0) as usize;
    let names: Vec<String> = if nel == 0 {
        vec![format!("Val{n}")]
    } else {
        (1..=nel).map(|i| format!("V{n}_{i}")).collect()
    };

    // Loading goes through the public put path, so MapLocked and KeyCase
    // apply to the loaded keys exactly as they do to a caller's puts.
    match ast_type {
        AstType::Int => {
            let v: Vec<i32> = names.iter().map(|nm| node.get_int(nm, 0) as i32).collect();
            put_loaded(km, key, nel, &v, comment, KeyMap::put_0i, KeyMap::put_1i)?;
        }
        // … the other eight arms, each with its own default: 0 for the
        // integer family and float, BAD_VALUE for double, "" for string,
        // and no value at all for Undef.
        AstType::Undef => km.put_u(key, comment)?,
        AstType::BadType => unreachable!("from_code rejects 0"),
    }
    Ok(())
}
```

### Task 15: property tests for order independence and round-trip idempotence

The whole `HashMap` decision rests on two properties, and neither is checkable by example alone:

1. **Order independence.** Two KeyMaps built from the same key/value set in different insertion orders must produce byte-identical dumps. `HashMap` iteration order is unspecified and varies run to run — `RandomState` seeds per process — so a missing sort in any order-exposing path shows up as a test that passes locally and fails in CI, or worse, passes for a year and then fails. These tests make the failure deterministic.
2. **Round-trip idempotence.** `dump → load → dump` must be a fixed point. Any asymmetry between `to_node` and `from_node` — a default that differs, a comment dropped, `MemCnt` recomputed rather than carried — shows up here and nowhere else.

`starlink-ast` has no dev-dependencies and the workspace pulls in no property-testing crate, so do **not** add `proptest`.
Adding a dependency for two tests is not the trade this project wants, and a hand-rolled deterministic generator is better here anyway: a fixed seed list means a CI failure reproduces exactly.

Note that `[workspace.lints.rust] warnings = "deny"` in the root `Cargo.toml` already makes local `cargo build` fail on warnings, so the generator has to be warning-clean, including `missing_docs` if any item is public. Keep it all private inside the test module.

```rust
//! Property tests for `KeyMap`.
//!
//! The two invariants that make the `HashMap`-backed storage safe: a dump is
//! independent of insertion order, and a dump/load cycle is a fixed point.

use starlink_ast::keymap::KeyMap;
use starlink_ast::{AnyObject, from_native_string, to_native_string};

/// A deterministic xorshift generator. Fixed seeds keep a CI failure
/// reproducible; `HashMap`'s own iteration order varies per process, which is
/// exactly what these tests are here to defeat.
struct Rng(u64);

impl Rng {
    fn new(seed: u64) -> Self {
        // A zero state is a fixed point for xorshift, so avoid it.
        Rng(seed | 1)
    }

    fn next_u64(&mut self) -> u64 {
        let mut x = self.0;
        x ^= x << 13;
        x ^= x >> 7;
        x ^= x << 17;
        self.0 = x;
        x
    }

    fn below(&mut self, n: usize) -> usize {
        (self.next_u64() % n as u64) as usize
    }

    fn shuffle<T>(&mut self, items: &mut [T]) {
        for i in (1..items.len()).rev() {
            let j = self.below(i + 1);
            items.swap(i, j);
        }
    }
}

/// One instruction for building a KeyMap. Ordering these differently is the
/// whole point, so every variant must be order-insensitive in its effect.
#[derive(Clone, Debug)]
enum Put {
    Int(String, i32),
    Short(String, i16),
    Long(String, i64),
    Byte(String, u8),
    Double(String, f64),
    Float(String, f32),
    Str(String, String),
    IntVec(String, Vec<i32>),
    StrVec(String, Vec<String>),
    DoubleVec(String, Vec<f64>),
    Undef(String),
    Nested(String, Vec<Put>),
}

/// Generate a random put list with unique keys. Keys are drawn to exercise
/// KeyCmp's digit handling and its case folding: mixed case, embedded
/// numbers, and lengths either side of a common prefix.
fn gen_puts(rng: &mut Rng, count: usize, depth: usize) -> Vec<Put> {
    const STEMS: &[&str] = &[
        "Alpha", "beta", "GAMMA", "delta9", "Delta10", "Delta2", "eps",
        "Epsilon", "z", "Zeta_1", "item", "Item", "a1b", "a10b", "a2b",
    ];
    let mut puts = Vec::with_capacity(count);
    for i in 0..count {
        // Suffix the stem with the index so keys stay unique regardless of
        // which stems were drawn.
        let key = format!("{}{}", STEMS[rng.below(STEMS.len())], i);
        let n = 1 + rng.below(4);
        puts.push(match rng.below(if depth > 0 { 12 } else { 11 }) {
            0 => Put::Int(key, rng.next_u64() as i32),
            1 => Put::Short(key, rng.next_u64() as i16),
            2 => Put::Long(key, rng.next_u64() as i64),
            3 => Put::Byte(key, rng.next_u64() as u8),
            // Values that stress the 17-significant-digit formatting, plus
            // BAD_VALUE, which is dumped as no card at all.
            4 => Put::Double(key, pick_double(rng)),
            5 => Put::Float(key, (rng.next_u64() as i32 as f32) / 7.0),
            6 => Put::Str(key, gen_string(rng)),
            7 => Put::IntVec(key, (0..n).map(|_| rng.next_u64() as i32).collect()),
            8 => Put::StrVec(key, (0..n).map(|_| gen_string(rng)).collect()),
            9 => Put::DoubleVec(key, (0..n).map(|_| pick_double(rng)).collect()),
            10 => Put::Undef(key),
            _ => Put::Nested(key, gen_puts(rng, 1 + rng.below(3), depth - 1)),
        });
    }
    puts
}

fn pick_double(rng: &mut Rng) -> f64 {
    const SPECIALS: &[f64] = &[
        starlink_ast::constants::BAD_VALUE,
        0.0,
        -0.0,
        1.0,
        -1.0,
        1e-300,
        1e300,
        std::f64::consts::PI,
    ];
    if rng.below(3) == 0 {
        SPECIALS[rng.below(SPECIALS.len())]
    } else {
        (rng.next_u64() as i64 as f64) / 1024.0
    }
}

/// Strings including the empty string, which MapGetC's fixed-stride
/// concatenation treats specially, and one with embedded spaces.
fn gen_string(rng: &mut Rng) -> String {
    const CHOICES: &[&str] = &["", "a", "Hello", "with space", "0123456789", "]"];
    CHOICES[rng.below(CHOICES.len())].to_string()
}

fn build(puts: &[Put]) -> KeyMap {
    let mut km = KeyMap::new();
    apply(&mut km, puts);
    km
}

fn apply(km: &mut KeyMap, puts: &[Put]) {
    for put in puts {
        match put {
            Put::Int(k, v) => km.put_0i(k, *v, None).unwrap(),
            Put::Short(k, v) => km.put_0s(k, *v, None).unwrap(),
            Put::Long(k, v) => km.put_0k(k, *v, None).unwrap(),
            Put::Byte(k, v) => km.put_0b(k, *v, None).unwrap(),
            Put::Double(k, v) => km.put_0d(k, *v, None).unwrap(),
            Put::Float(k, v) => km.put_0f(k, *v, None).unwrap(),
            Put::Str(k, v) => km.put_0c(k, v, None).unwrap(),
            Put::IntVec(k, v) => km.put_1i(k, v, None).unwrap(),
            Put::StrVec(k, v) => {
                let refs: Vec<&str> = v.iter().map(String::as_str).collect();
                km.put_1c(k, &refs, None).unwrap()
            }
            Put::DoubleVec(k, v) => km.put_1d(k, v, None).unwrap(),
            Put::Undef(k) => km.put_u(k, None).unwrap(),
            Put::Nested(k, inner) => {
                let obj = AnyObject::KeyMap(Box::new(build(inner)));
                km.put_0a(k, obj, None).unwrap()
            }
        }
    }
}

fn dump(km: &KeyMap) -> String {
    to_native_string(&AnyObject::KeyMap(Box::new(km.clone()))).unwrap()
}

fn load(text: &str) -> KeyMap {
    match from_native_string(text).unwrap() {
        AnyObject::KeyMap(km) => *km,
        other => panic!("expected a KeyMap, got {other:?}"),
    }
}

#[test]

        // puts cannot change the resulting content — only the member numbers,

        }
    }
}

    // being a stable permutation of the key set rather than for equality.
    use starlink_ast::SortBy;
    const MODES: &[SortBy] = &[
        SortBy::None,
        SortBy::AgeUp,
        SortBy::AgeDown,

            sorted.dedup();
            assert_eq!(

                km.map_size(),

            let again: Vec<String> =
                (0..km.map_size()).map(|i| km.map_key(i).unwrap()).collect();

                up.set_sort_by(SortBy::KeyUp);

                    (0..up.map_size()).map(|i| up.map_key(i).unwrap()).collect();
                let mut reversed = keys.clone();
                reversed.reverse();
                assert_eq!(
                    up_keys, reversed,
                    "seed {seed}: KeyDown is not the reverse of KeyUp"
                );
            }
        }
    }
}

        let a_puts = gen_puts(&mut rng, 3 + rng.below(8), 1);
        let mut b_puts = gen_puts(&mut rng, 3 + rng.below(8), 1);

        if let (Some(first), Some(target)) = (a_puts.first().cloned(), b_puts.first_mut()) {

                if let Some(src_key) = key_of(&first) {
                    *k = src_key;
                }
            }
        }

        let mut dest = build(&a_puts);
        dest.map_copy(&build(&b_puts)).unwrap();
        let reference = dump(&dest);

        for round in 0..3 {
            let mut a = a_puts.clone();
            let mut b = b_puts.clone();
            rng.shuffle(&mut a);
            rng.shuffle(&mut b);
            let mut dest = build(&a);
            dest.map_copy(&build(&b)).unwrap();
            assert_eq!(
                dump(&dest),
                reference,
                "seed {seed} round {round}: map_copy depends on insertion order"
            );
        }
    }
}
```

### Task 17: round-trip tests, the C fixture subtree, and the `MapSz` exclusion

Three separate jobs, in one file because they all test the serializer:

1. **Hand-built round trips.** One KeyMap per type code, scalar and vector, plus the attribute combinations. `dump → load → dump` must be byte-identical, and the reloaded values must equal the originals. This is the same shape as `test_native_roundtrip_all.rs`'s `assert_double_round_trip`, and for the same reason: the C fixture corpus only covers what some fixture happens to contain.
2. **The C fixture subtree.** `cap_timemap_02.map` holds one real C-generated KeyMap. Lift it out, parse it, dump it, and compare against the C bytes. This is the only place in the plan where C's own serializer output is the oracle.
3. **The `MapSz` exclusion.** `MapSz` records C's collision history and has no `HashMap` counterpart (design; `docs/issues/c-library-quirks.md:1629`). It is excluded from the byte comparison by a named helper, and separately asserted against `tests/fixtures/keymap/mapsz_oracle.txt` — the committed output of Task 4's C probe — so the exclusion does not hide a wrong value.

**Why the subtree has to be lifted rather than loaded whole.**
The enclosing object is a `StcResourceProfile`, which is a spec Non-goal, so `from_native_string` on the whole file cannot work.
Extracting the `Begin KeyMap` … `End KeyMap` block gives a self-contained Native document — every class inside it (`Box`, `CmpFrame`, `SkyFrame`, `TimeFrame`, `SpecFrame`, `Axis`, `SkyAxis`, `PointSet`) is already ported.

**What the comparison must allow for, and what it must not.**

Two differences are expected and are normalized away:

- **Indentation.** The fixture's block sits at base indent 6 (nested one level inside the `StcResourceProfile`); a standalone dump writes at base 0. Normalize every line by stripping leading whitespace, and — for a commented-out unset attribute — the leading `#` and the whitespace after it, keeping a flag that the card was commented. This makes the comparison indentation-blind without discarding the set/unset distinction.
- **Entry order.** C dumps entries in hash-bucket order (`Size`, `Name`, `Resolution`, `Error`); the port dumps in `KeyCmp` order (`Error`, `Name`, `Resolution`, `Size`), which is the whole point of the design's idempotence property. So the entry *blocks* are compared as a map keyed by the entry's key name, with the `%d` index in every card name replaced by `#`. Two entries whose cards match after renumbering are equal.

Nothing else is allowed.
In particular the `Typ%d` comment text, the `Nel%d` presence rule, the `V%d_%d` first-element-only comment, the quoting of strings, and every card inside the nested `Box` objects must match byte for byte.

**Splitting the KeyMap's own cards from a nested object's.**
Do this **before** normalizing indentation, using the column.
The `Begin KeyMap` line's leading-space count is `base`; the KeyMap's own cards sit at exactly `base + 4` (`native_write.rs:179`: `base_indent + indent + 1`, at the default `indent = 3`), and its commented-out unset attributes at `#` plus `base + 3` spaces.
A `Key%d` card at any other column belongs to a nested KeyMap and must not start an entry block at this level.
The fixture has no nested KeyMap, but the hand-built cases in job 1 do, and the same helper serves both.

```rust
//! KeyMap serialisation: hand-built round trips, the one real C-generated
//! KeyMap in the fixture corpus, and the `MapSz` C oracle.
//!
//! `MapSz` is excluded from the byte-exact comparison and asserted
//! separately against the C probe's committed output; see
//! `common::is_map_sz_card` and `tests/fixtures/keymap/mapsz_oracle.txt`.

mod common;

use starlink_ast::keymap::{KeyMap, SortBy};
use starlink_ast::{AnyObject, from_native_string, to_native_string};
use std::collections::BTreeMap;

/// One card of a Native dump, with indentation removed.
///
/// `commented` records whether the card was written as an unset attribute
/// (`#   Title = …`), which the writer uses to mean "this is the default".
#[derive(Debug, PartialEq, Eq, Clone)]
struct Card {
    commented: bool,
    content: String,
}

fn normalise(line: &str) -> Card {
    let s = line.trim_start();
    if let Some(rest) = s.strip_prefix('#') {
        Card {
            commented: true,
            content: rest.trim_start().to_string(),
        }
    } else {
        Card {
            commented: false,
            content: s.to_string(),
        }
    }
}

/// The number of leading spaces on a line, treating a commented-out card's
/// `#` as occupying column 0.
fn column(line: &str) -> usize {
    let body = line.strip_prefix('#').unwrap_or(line);
    let indent = body.len() - body.trim_start().len();
    if line.starts_with('#') { indent } else { indent }
}

/// Replace the trailing digits of a card name with `#`, so `Key3` and `Key1`
/// compare equal and `V3_2` compares equal to `V1_2`.
///
/// Entry cards are `Key<n>`, `Com<n>`, `Typ<n>`, `Nel<n>`, `Val<n>` and
/// `V<n>_<i>`; only the entry index `<n>` is renumbered, never the element
/// index `<i>`.
fn renumber(content: &str) -> String {
    let Some((name, rest)) = content.split_once(" =") else {
        return content.to_string();
    };
    let renamed = if let Some((head, tail)) = name.split_once('_') {
        // V<n>_<i>: renumber the entry index, keep the element index.
        format!("{}#_{tail}", head.trim_end_matches(|c: char| c.is_ascii_digit()))
    } else {
        let stem = name.trim_end_matches(|c: char| c.is_ascii_digit());
        if stem.len() == name.len() {
            name.to_string()
        } else {
            format!("{stem}#")
        }
    };
    format!("{renamed} ={rest}")
}

/// A KeyMap dump split into its attribute cards and its per-entry blocks.
#[derive(Debug, PartialEq, Eq)]
struct Split {
    /// The cards before the first `Key<n>`, in order.
    header: Vec<Card>,
    /// Entry blocks keyed by the entry's key name, each renumbered.
    entries: BTreeMap<String, Vec<Card>>,
}

/// Split the `Begin KeyMap` … `End KeyMap` block that `lines` consists of.
///
/// Only cards at the block's own attribute column start a new entry; a
/// `Key<n>` card belonging to a nested KeyMap stays inside the enclosing
/// entry's block, where it belongs.
fn split_keymap(text: &str) -> Split {
    let lines: Vec<&str> = text.lines().filter(|l| !l.trim().is_empty()).collect();
    let begin = lines
        .iter()
        .position(|l| l.trim_start().starts_with("Begin KeyMap"))
        .expect("no Begin KeyMap");
    let base = column(lines[begin]) ;
    let own = base + 4;

    let mut header = Vec::new();
    let mut entries: BTreeMap<String, Vec<Card>> = BTreeMap::new();
    let mut current: Option<String> = None;

    for line in &lines[begin + 1..] {
        if line.trim_start().starts_with("End KeyMap") && column(line) == base {
            break;
        }
        let card = normalise(line);
        let starts_entry = column(line) == own
            && !card.commented
            && card.content.starts_with("Key")
            && card
                .content
                .split_once(" =")
                .is_some_and(|(n, _)| n[3..].chars().all(|c| c.is_ascii_digit()) && n.len() > 3);

        if starts_entry {
            let key = card
                .content
                .split_once(" =")
                .unwrap()
                .1
                .split('\t')
                .next()
                .unwrap()
                .trim()
                .trim_matches('"')
                .to_string();
            current = Some(key.clone());
            entries.entry(key).or_default();
        }

        let target = match &current {
            Some(k) => entries.get_mut(k).unwrap(),
            None => &mut header,
        };
        target.push(Card {
            commented: card.commented,
            content: renumber(&card.content),
        });
    }

    Split { header, entries }
}
```

`column` as written has an `if`/`else` with identical arms; that is a placeholder for whichever convention the writer actually uses.

```rust
/// `<label> sizeguess=<n> nkey=<n> MapSz=<n>`, label left-padded to 28.

        if line.is_empty() {

        }

            let at = line
                .find(name)
                .unwrap_or_else(|| panic!("no {name} in oracle row {line:?}"));
            line[at + name.len()..]
                .split_whitespace()
                .next()
                .unwrap()
                .parse()
                .unwrap()

            label: line[..label_end].trim().to_string(),
            sizeguess: field("sizeguess=") as i32,
            nkey: field("nkey=") as usize,
            map_sz: field("MapSz="),
        });
    }
    assert!(!rows.is_empty(), "oracle fixture is empty");
    rows

/// The first `n` keys of the form `K<i>` that hash to bucket 5 of a
/// 16-bucket table, by the same rule Task 4's probe and Task 3's
/// `colliding_keys` use. Duplicated here rather than shared because a test
/// crate cannot reach `keymap::table`'s private helpers, and because the
/// point is that three independent restatements of djb2 agree.
fn colliding_keys(n: usize) -> Vec<String> {
    let mut out = Vec::with_capacity(n);
    let mut i = 0u64;
    while out.len() < n {
        let key = format!("K{i}");
        let mut hash: u64 = 5381;
        for b in key.bytes() {
            if b != b' ' {
                hash = hash.wrapping_shl(5).wrapping_add(hash).wrapping_add(b as u64);
            }
        }
        if (hash & 15) == 5 {
            out.push(key);
        }
        i += 1;
    }
    out
}

///
/// Returns `None` for a label this test does not know how to reproduce, so
/// that adding a row to the probe cannot silently do nothing here — the
/// caller counts what it skipped and fails if the count grows.
fn key_map_for(row: &OracleRow) -> Option<KeyMap> {
    let mut km = KeyMap::new();
    if row.sizeguess > 0 {
        km.set_size_guess(row.sizeguess as usize).unwrap();
    }
    let keys: Vec<String> = match row.label.as_str() {
        "empty" | "four keys" | "100 keys" | "500 keys" | "1000 keys" | "guess 100"
        | "guess 160" | "guess 170" | "guess 5000" | "guess 5000, 500 keys" => {
            (0..row.nkey).map(|i| format!("KEY_{i}")).collect()
        }
        "500 keys, k%d" => (0..row.nkey).map(|i| format!("k{i}")).collect(),
        "500 keys, ZZ%d_TAIL" => (0..row.nkey).map(|i| format!("ZZ{i}_TAIL")).collect(),
        "cap_timemap_02 keys" => ["Size", "Name", "Resolution", "Error"]
            .iter()
            .map(|s| s.to_string())
            .collect(),
        "10 colliding" | "11 colliding" | "40 colliding" | "300 colliding" => {
            colliding_keys(row.nkey)

        "40 colliding + 40 spread" => {

            v.extend((0..40).map(|i| format!("SPREAD_{i}")));

        }
        _ => return None,
    };
    for (i, key) in keys.iter().enumerate() {
        km.put_0i(key, i as i32, None).unwrap();
    }
    Some(km)
}

#[test]
```
```rust
fn every_attribute_round_trips() {

    km.set_sort_by(SortBy::KeyDown);

}

        }
    }
```
