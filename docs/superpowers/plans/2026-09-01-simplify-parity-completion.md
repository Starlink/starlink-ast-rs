> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every outstanding simplifier divergence between this port and the pinned C library, so that all 468 `.map` / `.simp` fixtures byte-compare and the audit instrument proves nothing was missed.

**Architecture:** Work proceeds as paired closeout by cluster — each cluster ports a group of related C logic and drives the fixtures that group unblocks to byte-equality in the same commit range.

The verification-posture ledger is the ratchet throughout: it asserts exact counts, so a partial fix cannot land quietly.

**Tech Stack:** Rust 2024 (`ast-core`), C99 oracle probes under `tools/oracle_fixtures/` linked against `reference/starlink-ast`, `cargo test -p ast-core`, `cargo fmt`, `cargo clippy`.

## Global Constraints

- **The `reference/starlink-ast` pin is frozen at `3e60abaa` for the whole plan.** Every C line number recorded anywhere is against that pin. Do not `git -C reference/starlink-ast checkout` anything, and do not stage a gitlink change.
- **Byte-equal `.map` / `.simp` output is the only accepted evidence.** A passing `astEqual` assertion is never accepted in its place (spec §1.1).
- **Never hand-edit a `.simp` or `.map` reference fixture.** Regenerate it from the C oracle. Every new fixture is generated by a program under `tools/oracle_fixtures/` (spec §5.2).
- **No skip mode.** A case that cannot be compared goes in a named exclusion list with a per-case reason and a ledger row asserting its exact size. Data-driven harnesses hard-fail. Never widen a global tolerance or loosen a negative control.
- **No tolerance, threshold or iteration count without a C analogue.** Grep the C source for the constant first; if C gets the right answer without it, C is doing something structurally different (`CLAUDE.md`, stop signal 1).
- **Mirror C's control flow directly.** C logic beats existing Rust shape at any stage. Port the whole algorithm; "no fixture exercises it" is a reason to add a fixture, not to skip a branch.
- **Aliasing and refcount-driven dump artifacts go in `docs/issues/c-library-quirks.md`, never into Rust code.**
- **Comments and docstrings describe the code as it is today.** No references to this plan, to previous attempts, or to history.
- **One sentence per line** in Markdown prose. American English in prose; existing British spellings in filenames and identifiers (`test_serialisation.rs`, `serialise`) stay as they are.
- **Every commit runs `cargo fmt` and clippy.** Export the toolchain first or the pre-commit hook fails with `error[E0514]`:

```rust
//! Source citations for the `MapMerge` / `Simplify` audit checklists.
//!
//! A checklist row cites a source line, and a line number rots as the file
//! around it changes. Recording the enclosing item's name beside the number
//! makes the rot detectable: the number and the name have to still agree.
//! This crate holds the one derivation of that name, so the tool that writes
//! the citations and the test that checks them cannot disagree about it.

/// A parsed `file:line[-line] [(fn name)]` citation.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Citation {
    /// File name as written, without a directory.
    pub file: String,
    /// First line of the cited range, 1-based.
    pub start: usize,
    /// Last line of the cited range, when the citation names one.
    pub end: Option<usize>,
    /// The item name the citation claims, when it carries one.
    pub item: Option<String>,
}

fn is_ident(c: char) -> bool {
    c.is_alphanumeric() || c == '_'
}

/// Parse the first citation in `text`.
pub fn parse_citation(text: &str) -> Option<Citation> {
    for (colon, _) in text.match_indices(':') {
        let stem: String = text[..colon]
            .chars()
            .rev()
            .take_while(|c| is_ident(*c) || *c == '.')
            .collect();
        let file: String = stem.chars().rev().collect();
        if !(file.ends_with(".rs") || file.ends_with(".c") || file.ends_with(".h")) {
            continue;
        }
        let after = &text[colon + 1..];
        let digits: String = after.chars().take_while(char::is_ascii_digit).collect();
        let Ok(start) = digits.parse::<usize>() else {
            continue;
        };
        let mut rest = &after[digits.len()..];
        let mut end = None;
        if let Some(tail) = rest.strip_prefix('-') {
            let d: String = tail.chars().take_while(char::is_ascii_digit).collect();
            if let Ok(n) = d.parse::<usize>() {
                end = Some(n);
                rest = &tail[d.len()..];
            }
        }
        let item = rest
            .trim_start()
            .strip_prefix("(fn ")
            .and_then(|t| t.split_once(')'))
            .map(|(name, _)| name.trim().to_string());
        return Some(Citation { file, start, end, item });
    }
    None
}

/// Strip line comments and string / char literal bodies so their braces do not
/// count as block structure.
fn code_only(line: &str) -> String {
    let mut out = String::with_capacity(line.len());
    let bytes: Vec<char> = line.chars().collect();
    let mut i = 0;
    while i < bytes.len() {
        match bytes[i] {
            '/' if bytes.get(i + 1) == Some(&'/') => break,
            '"' => {
                i += 1;
                while i < bytes.len() {
                    match bytes[i] {
                        '\\' => i += 2,
                        '"' => break,
                        _ => i += 1,
                    }
                }
                i += 1;
            }
            '\'' if bytes.get(i + 1) == Some(&'{') || bytes.get(i + 1) == Some(&'}') => i += 3,
            c => {
                out.push(c);
                i += 1;
            }
        }
    }
    out
}

fn rust_fn_name(code: &str) -> Option<String> {
    let at = code.find("fn ").filter(|at| {
        *at == 0 || !code[..*at].chars().next_back().is_some_and(is_ident)
    })?;
    let name: String = code[at + 3..].chars().take_while(|c| is_ident(*c)).collect();
    (!name.is_empty()).then_some(name)
}

/// The name of the `fn` whose body contains `line` (1-based).
pub fn enclosing_rust_item(src: &str, line: usize) -> Option<String> {
    let mut stack: Vec<(String, usize)> = Vec::new();
    let mut depth = 0usize;
    let mut pending: Option<String> = None;
    for (i, text) in src.lines().enumerate() {
        let code = code_only(text);
        if let Some(name) = rust_fn_name(&code) {
            pending = Some(name);
        }
        for c in code.chars() {
            match c {
                '{' => {
                    depth += 1;
                    if let Some(name) = pending.take() {
                        stack.push((name, depth));
                    }
                }
                '}' => {
                    if stack.last().is_some_and(|(_, d)| *d == depth) {
                        stack.pop();
                    }
                    depth = depth.saturating_sub(1);
                }
                // A signature with no body, as in a trait declaration.
                ';' => pending = None,
                _ => {}
            }
        }
        if i + 1 == line {
            return stack.last().map(|(name, _)| name.clone());
        }
    }
    None
}

/// The name of the C function whose body contains `line` (1-based).
pub fn enclosing_c_function(src: &str, line: usize) -> Option<String> {
    c_functions(src)
        .into_iter()
        .find(|(_, start, end)| *start <= line && line <= *end)
        .map(|(name, _, _)| name)
}

/// Every function definition in `src`, as `(name, first line, last line)`.
///
/// AST's house style puts a definition's declarator at column 0 and its closing
/// brace alone at column 0, so a definition is delimited without parsing C.
pub fn c_functions(src: &str) -> Vec<(String, usize, usize)> {
    let lines: Vec<&str> = src.lines().collect();
    let mut out = Vec::new();
    let mut i = 0;
    while i < lines.len() {
        match c_definition_name(&lines, i) {
            Some(name) => {
                let mut j = i + 1;
                while j < lines.len() && lines[j] != "}" {
                    j += 1;
                }
                out.push((name, i + 1, j + 1));
                i = j + 1;
            }
            None => i += 1,
        }
    }
    out
}

/// The name of the function defined at `lines[i]`, if a definition starts there.
///
/// What separates a definition from the prototype of the same name earlier in
/// the file is where the declarator ends: a definition reaches `{` with its
/// parameter list balanced, a prototype reaches `;`.
fn c_definition_name(lines: &[&str], i: usize) -> Option<String> {
    if !lines[i].chars().next().is_some_and(is_ident) {
        return None;
    }
    let open = lines[i].find('(')?;
    let mut depth = 0i32;
    let mut opened = false;
    'scan: for text in lines.iter().skip(i).take(9) {
        for c in text.chars() {
            match c {
                '(' => {
                    depth += 1;
                    opened = true;
                }
                ')' => depth -= 1,
                '{' if opened && depth == 0 => break 'scan,
                ';' if opened && depth == 0 => return None,
                _ => {}
            }
        }
    }
    let ident: String = lines[i][..open]
        .trim_end()
        .chars()
        .rev()
        .take_while(|c| is_ident(*c))
        .collect();
    (!ident.is_empty()).then(|| ident.chars().rev().collect())
}
```

```rust
//! Rewrite a checklist's citations into `file:line (fn name)` form.
//!
//! Reports every row it cannot anchor instead of relocating it. A citation that
//! was wrong when it was written stays wrong under any mechanical remap, so the
//! rows this reports need a per-row re-anchor against the code they describe.
//!
//! Usage: anchor-citations <checklist.md>...
//!   --write   rewrite in place; without it, print what would change

use std::path::{Path, PathBuf};

fn repo_root() -> PathBuf {
    let mut dir = std::env::current_dir().expect("cwd readable");
    while !dir.join("PLAN.md").is_file() {
        dir = dir.parent().expect("run inside the repository").to_path_buf();
    }
    dir
}

fn resolve(root: &Path, file: &str) -> Option<PathBuf> {
    if file.ends_with(".rs") {
        let mut stack = vec![root.join("crates/ast-core/src")];
        let mut found = None;
        while let Some(dir) = stack.pop() {
            for entry in std::fs::read_dir(&dir).ok()? {
                let path = entry.ok()?.path();
                if path.is_dir() {
                    stack.push(path);
                } else if path.file_name().and_then(|f| f.to_str()) == Some(file) {
                    found = Some(path);
                }
            }
        }
        found
    } else {
        let path = root.join("reference/starlink-ast/src").join(file);
        path.is_file().then_some(path)
    }
}

fn main() {
    let root = repo_root();
    let args: Vec<String> = std::env::args().skip(1).collect();
    let write = args.iter().any(|a| a == "--write");
    let mut unanchored = 0usize;
    for arg in args.iter().filter(|a| !a.starts_with("--")) {
        let path = PathBuf::from(arg);
        let text = std::fs::read_to_string(&path).expect("checklist readable");
        let mut out = String::with_capacity(text.len());
        for (i, line) in text.lines().enumerate() {
            let mut rebuilt = line.to_string();
            for cell in line.split('|') {
                let Some(cit) = audit_tools::parse_citation(cell) else {
                    continue;
                };
                if cit.item.is_some() {
                    continue;
                }
                let Some(src_path) = resolve(&root, &cit.file) else {
                    continue;
                };
                let src = std::fs::read_to_string(&src_path).expect("source readable");
                let item = if cit.file.ends_with(".rs") {
                    audit_tools::enclosing_rust_item(&src, cit.start)
                } else {
                    audit_tools::enclosing_c_function(&src, cit.start)
                };
                match item {
                    Some(name) => {
                        let bare = match cit.end {
                            Some(e) => format!("{}:{}-{}", cit.file, cit.start, e),
                            None => format!("{}:{}", cit.file, cit.start),
                        };
                        rebuilt = rebuilt.replacen(&bare, &format!("{bare} (fn {name})"), 1);
                    }
                    None => {
                        unanchored += 1;
                        println!(
                            "{}:{}: {}:{} is not inside any item — re-anchor by hand",
                            path.display(),
                            i + 1,
                            cit.file,
                            cit.start
                        );
                    }
                }
            }
            out.push_str(&rebuilt);
            out.push('\n');
        }
        if write {
            std::fs::write(&path, out).expect("checklist writable");
        } else {
            print!("{out}");
        }
    }
    if unanchored > 0 {
        eprintln!("{unanchored} citations could not be anchored");
        std::process::exit(1);
    }
}
```

```rust
/// The `impl` header enclosing `line` (1-based), as `"Trait for Type"` when the
/// block implements a trait and `"Type"` when it does not.
///
/// This is what distinguishes a step that landed on a trait method — the port's
/// equivalent of a C vtab slot — from one that landed on an inherent helper.
pub fn enclosing_rust_impl(src: &str, line: usize) -> Option<String> {
    let mut stack: Vec<(String, usize)> = Vec::new();
    let mut depth = 0usize;
    let mut pending: Option<String> = None;
    for (i, text) in src.lines().enumerate() {
        let code = code_only(text);
        if let Some(header) = impl_header(&code) {
            pending = Some(header);
        }
        for c in code.chars() {
            match c {
                '{' => {
                    depth += 1;
                    if let Some(header) = pending.take() {
                        stack.push((header, depth));
                    }
                }
                '}' => {
                    if stack.last().is_some_and(|(_, d)| *d == depth) {
                        stack.pop();
                    }
                    depth = depth.saturating_sub(1);
                }
                _ => {}
            }
        }
        if i + 1 == line {
            return stack.last().map(|(header, _)| header.clone());
        }
    }
    None
}

/// The subject of an `impl` line, with generics and `where` clauses removed.
fn impl_header(code: &str) -> Option<String> {
    let trimmed = code.trim_start();
    let rest = trimmed.strip_prefix("impl")?;
    if rest.starts_with(|c: char| is_ident(c)) {
        return None;
    }
    let body = rest
        .split(" where ")
        .next()
        .unwrap_or(rest)
        .split('{')
        .next()
        .unwrap_or(rest);
    let mut out = String::new();
    let mut generic = 0i32;
    for c in body.chars() {
        match c {
            '<' => generic += 1,
            '>' => generic -= 1,
            _ if generic == 0 => out.push(c),
            _ => {}
        }
    }
    let header = out.split_whitespace().collect::<Vec<_>>().join(" ");
    (!header.is_empty()).then_some(header)
}
```

```rust
//! Enumerating the steps of a C seam body from the source.
//!
//! AST's house style precedes every step inside a function body with a comment
//! block starting at column 0. Deriving the steps from those comments keeps the
//! audit's universe of steps out of any hand-maintained list: a step that is
//! present in C and absent from a checklist is then a detectable omission
//! rather than an invisible one.

use crate::c_functions;

/// The line and text of each column-0 comment block inside `function`'s body.
///
/// A block's text is joined onto one line with runs of whitespace collapsed, so
/// a comment that wraps in the source compares as what it says.
pub fn c_step_comments(src: &str, function: &str) -> Vec<(usize, String)> {
    let lines: Vec<&str> = src.lines().collect();
    let Some((_, start, end)) = c_functions(src)
        .into_iter()
        .find(|(name, _, _)| name == function)
    else {
        return Vec::new();
    };
    let mut out = Vec::new();
    let mut i = start; // Skip the declarator line itself.
    while i + 1 < end {
        let text = lines[i];
        if !text.starts_with("/*") {
            i += 1;
            continue;
        }
        let first = i;
        let mut body = String::new();
        loop {
            body.push(' ');
            body.push_str(lines[i]);
            if lines[i].contains("*/") || i + 1 >= end {
                break;
            }
            i += 1;
        }
        let cleaned = body
            .trim()
            .trim_start_matches("/*")
            .trim_end_matches("*/")
            .split_whitespace()
            .collect::<Vec<_>>()
            .join(" ");
        out.push((first + 1, cleaned));
        i += 1;
    }
    out
}
```

## Cluster 1 — the `IsSimp` card

Three fixtures in this cluster: `cefit_circle_conformal` and
`cefit_circle_nonconformal_keep` (rows B in `SERIAL_UNGATED`, and two of the
seven `ISSIMP_DISAGREEMENTS` rows) and `neg_box_asymmetric_2d` (the single
`NO_ISSIMP_CARD_UNGATED` row).
They rest on two C rules the port does not have, both read off the pinned
source.

**Rule 1 — a Frame never reports `IsSimple`.**
`frame.c:5590` overrides the protected `astGetIsSimple` method and returns 0
unconditionally, "because Frames are not immutable (unlike non-Frame
Mappings)".
Every FrameSet and every Region inherits that override, so `mapping.c:23781`,
which writes the card only when `astGetIsSimple` is non-zero, never writes one
for a Frame-kind object however many times `astSimplify` has stamped it.
The port reproduces the *output* by accident — no Frame-kind class holds a
`SimplifiedRecord`, so the `Mapping` trait defaults at
`crates/ast-core/src/mappings/mod.rs:564-582` return `false` — but the harness
asserts the opposite, requiring a card on every simplified result
(`test_simplify_regression.rs:402-406`), and `neg_box_asymmetric_2d` is licensed
out of that wrong assertion rather than gated by the right one.

**Rule 2 — the card is discarded on load whenever the class's own loader routes
an attribute through a clearing setter.**
Upstream `e40e71b4` made a setter for an attribute that feeds the first part of
its class's own `astMapMerge` discard both simplified records
(`mapping.h:449-460`, PLAN.md §9.2).
Every loader for those classes assigns the attribute *through that setter* —
`astLoadZoomMap` at `zoommap.c:2238` calls `SetZoom`, whose `astMAKE_SET1` at
`zoommap.c:1704` calls `astClearIsSimple` — and `astLoadMapping` has already
installed the record from the `IsSimp` card by then (`mapping.c:24137`, which
runs in the parent before any class-specific card is read).
So for those classes a dumped `IsSimp = 1` does not survive being read back.

The corpus discriminates rule 2 on two matched pairs, same class and same
nesting depth, differing only in whether a clearing attribute is present:

| fixture | class | clearing attribute in the `.map` | `IsSimp` in C's `.simp` |
|---|---|---|---|
| `cefit_circle_conformal` | ZoomMap | `Zoom = 2` | absent |
| `cap_poly_unc_frame` | ZoomMap | `Zoom = 4` | present |
| `cefit_circle_nonconformal_keep` | MathMap | `SimpFI = 1`, `SimpIF = 1` | absent |
| `cap_poly_bent_edges` | MathMap | none | present |

The two "present" rows are not counter-examples, and they are this cluster's
negative controls.
Where the record is cleared on load, a card can still reappear, because
`astSimplify_` stamps whatever the vtab slot returns and the base `Simplify`
returns `astClone(this)` — the same pointer — so the stamp lands on the object
already in the tree.
`FrameSet::Simplify` keeps that stamp only when some edge reduced:
`astClone( simpler ? new : this )` at `frameset.c:10226` discards the whole deep
copy otherwise, stamps and all.
`cap_poly_unc_frame` reaches its ZoomMap through a path that adopts the copy;
`cefit_circle_conformal` does not, so its original — cleared at load — is what C
dumps.
That is the `flags = 0` object PLAN.md §9.1 saw and read as freshly constructed:
it is the original, and the constructor it was looking for does not exist.
`cap_poly_bent_edges` never loses the record at all, because its MathMap carries
no `SimpFI` / `SimpIF` / `Seeded` card and `TestSimpFI` is therefore false.

`FrameSet::simplified` (`crates/ast-core/src/frames/frameset.rs:1647-1670`)
already mirrors `frameset.c:10111` edge for edge, including the unconditional

pointer, so rule 2 is the only missing piece on the port side.
