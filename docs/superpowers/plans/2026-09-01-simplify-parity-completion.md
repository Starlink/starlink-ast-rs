> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every outstanding simplifier divergence between this port and the pinned C library, so that all 468 `.map` / `.simp` fixtures byte-compare and the audit instrument proves nothing was missed.

**Architecture:** Work proceeds as paired closeout by cluster — each cluster ports a group of related C logic and drives the fixtures that group unblocks to byte-equality in the same commit range.

The verification-posture ledger is the ratchet throughout: it asserts exact counts, so a partial fix cannot land quietly.

**Tech Stack:** Rust 2024 (`ast-core`), C99 oracle probes under `tools/oracle_fixtures/` linked against `reference/starlink-ast`, `cargo test -p ast-core`, `cargo fmt`, `cargo clippy`.

## Global Constraints

- **The `reference/starlink-ast` pin is frozen at `3e60abaa` for the whole plan.** Every C line number recorded anywhere is against that pin. Do not `git -C reference/starlink-ast checkout` anything, and do not stage a gitlink change.
- **Byte-equal `.map` / `.simp` output is the only accepted evidence.** A passing `astEqual` assertion is never accepted in its place (spec §1.1).
- **Never hand-edit a `.simp` or `.map` reference fixture.** Regenerate it from the C oracle. Every new fixture is generated by a program under `tools/oracle_fixtures/` (spec §5.2).
- **No skip mode.** A case that cannot be compared goes in a named exclusion list with a per-case reason and a ledger row asserting its exact size. Data-driven harnesses hard-fail. Never widen a global tolerance or loosen a negative control.
- **No tolerance, threshold or iteration count without a C analogue.** Grep the C source for the constant first; if C gets the right answer without it, C is doing something structurally different (`CLAUDE.md`, stop signal 1).
- **Mirror C's control flow directly.** C logic beats existing Rust shape at any stage. Port the whole algorithm; "no fixture exercises it" is a reason to add a fixture, not to skip a branch.
- **Aliasing and refcount-driven dump artifacts go in `docs/issues/c-library-quirks.md`, never into Rust code.**
- **Comments and docstrings describe the code as it is today.** No references to this plan, to previous attempts, or to history.
- **One sentence per line** in Markdown prose. American English in prose; existing British spellings in filenames and identifiers (`test_serialisation.rs`, `serialise`) stay as they are.
- **Every commit runs `cargo fmt` and clippy.** Export the toolchain first or the pre-commit hook fails with `error[E0514]`:

```rust
//! Source citations for the `MapMerge` / `Simplify` audit checklists.
//!
//! A checklist row cites a source line, and a line number rots as the file
//! around it changes. Recording the enclosing item's name beside the number
//! makes the rot detectable: the number and the name have to still agree.
//! This crate holds the one derivation of that name, so the tool that writes
//! the citations and the test that checks them cannot disagree about it.

/// A parsed `file:line[-line] [(fn name)]` citation.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Citation {
    /// File name as written, without a directory.
    pub file: String,
    /// First line of the cited range, 1-based.
    pub start: usize,
    /// Last line of the cited range, when the citation names one.
    pub end: Option<usize>,
    /// The item name the citation claims, when it carries one.
    pub item: Option<String>,
}

fn is_ident(c: char) -> bool {
    c.is_alphanumeric() || c == '_'
}

/// Parse the first citation in `text`.
pub fn parse_citation(text: &str) -> Option<Citation> {
    for (colon, _) in text.match_indices(':') {
        let stem: String = text[..colon]
            .chars()
            .rev()
            .take_while(|c| is_ident(*c) || *c == '.')
            .collect();
        let file: String = stem.chars().rev().collect();
        if !(file.ends_with(".rs") || file.ends_with(".c") || file.ends_with(".h")) {
            continue;
        }
        let after = &text[colon + 1..];
        let digits: String = after.chars().take_while(char::is_ascii_digit).collect();
        let Ok(start) = digits.parse::<usize>() else {
            continue;
        };
        let mut rest = &after[digits.len()..];
        let mut end = None;
        if let Some(tail) = rest.strip_prefix('-') {
            let d: String = tail.chars().take_while(char::is_ascii_digit).collect();
            if let Ok(n) = d.parse::<usize>() {
                end = Some(n);
                rest = &tail[d.len()..];
            }
        }
        let item = rest
            .trim_start()
            .strip_prefix("(fn ")
            .and_then(|t| t.split_once(')'))
            .map(|(name, _)| name.trim().to_string());
        return Some(Citation { file, start, end, item });
    }
    None
}

/// Strip line comments and string / char literal bodies so their braces do not
/// count as block structure.
fn code_only(line: &str) -> String {
    let mut out = String::with_capacity(line.len());
    let bytes: Vec<char> = line.chars().collect();
    let mut i = 0;
    while i < bytes.len() {
        match bytes[i] {
            '/' if bytes.get(i + 1) == Some(&'/') => break,
            '"' => {
                i += 1;
                while i < bytes.len() {
                    match bytes[i] {
                        '\\' => i += 2,
                        '"' => break,
                        _ => i += 1,
                    }
                }
                i += 1;
            }
            '\'' if bytes.get(i + 1) == Some(&'{') || bytes.get(i + 1) == Some(&'}') => i += 3,
            c => {
                out.push(c);
                i += 1;
            }
        }
    }
    out
}

fn rust_fn_name(code: &str) -> Option<String> {
    let at = code.find("fn ").filter(|at| {
        *at == 0 || !code[..*at].chars().next_back().is_some_and(is_ident)
    })?;
    let name: String = code[at + 3..].chars().take_while(|c| is_ident(*c)).collect();
    (!name.is_empty()).then_some(name)
}

/// The name of the `fn` whose body contains `line` (1-based).
pub fn enclosing_rust_item(src: &str, line: usize) -> Option<String> {
    let mut stack: Vec<(String, usize)> = Vec::new();
    let mut depth = 0usize;
    let mut pending: Option<String> = None;
    for (i, text) in src.lines().enumerate() {
        let code = code_only(text);
        if let Some(name) = rust_fn_name(&code) {
            pending = Some(name);
        }
        for c in code.chars() {
            match c {
                '{' => {
                    depth += 1;
                    if let Some(name) = pending.take() {
                        stack.push((name, depth));
                    }
                }
                '}' => {
                    if stack.last().is_some_and(|(_, d)| *d == depth) {
                        stack.pop();
                    }
                    depth = depth.saturating_sub(1);
                }
                // A signature with no body, as in a trait declaration.
                ';' => pending = None,
                _ => {}
            }
        }
        if i + 1 == line {
            return stack.last().map(|(name, _)| name.clone());
        }
    }
    None
}

/// The name of the C function whose body contains `line` (1-based).
pub fn enclosing_c_function(src: &str, line: usize) -> Option<String> {
    c_functions(src)
        .into_iter()
        .find(|(_, start, end)| *start <= line && line <= *end)
        .map(|(name, _, _)| name)
}

/// Every function definition in `src`, as `(name, first line, last line)`.
///
/// AST's house style puts a definition's declarator at column 0 and its closing
/// brace alone at column 0, so a definition is delimited without parsing C.
pub fn c_functions(src: &str) -> Vec<(String, usize, usize)> {
    let lines: Vec<&str> = src.lines().collect();
    let mut out = Vec::new();
    let mut i = 0;
    while i < lines.len() {
        match c_definition_name(&lines, i) {
            Some(name) => {
                let mut j = i + 1;
                while j < lines.len() && lines[j] != "}" {
                    j += 1;
                }
                out.push((name, i + 1, j + 1));
                i = j + 1;
            }
            None => i += 1,
        }
    }
    out
}

/// The name of the function defined at `lines[i]`, if a definition starts there.
///
/// What separates a definition from the prototype of the same name earlier in
/// the file is where the declarator ends: a definition reaches `{` with its
/// parameter list balanced, a prototype reaches `;`.
fn c_definition_name(lines: &[&str], i: usize) -> Option<String> {
    if !lines[i].chars().next().is_some_and(is_ident) {
        return None;
    }
    let open = lines[i].find('(')?;
    let mut depth = 0i32;
    let mut opened = false;
    'scan: for text in lines.iter().skip(i).take(9) {
        for c in text.chars() {
            match c {
                '(' => {
                    depth += 1;
                    opened = true;
                }
                ')' => depth -= 1,
                '{' if opened && depth == 0 => break 'scan,
                ';' if opened && depth == 0 => return None,
                _ => {}
            }
        }
    }
    let ident: String = lines[i][..open]
        .trim_end()
        .chars()
        .rev()
        .take_while(|c| is_ident(*c))
        .collect();
    (!ident.is_empty()).then(|| ident.chars().rev().collect())
}
```

```rust
//! Rewrite a checklist's citations into `file:line (fn name)` form.
//!
//! Reports every row it cannot anchor instead of relocating it. A citation that
//! was wrong when it was written stays wrong under any mechanical remap, so the
//! rows this reports need a per-row re-anchor against the code they describe.
//!
//! Usage: anchor-citations <checklist.md>...
//!   --write   rewrite in place; without it, print what would change

use std::path::{Path, PathBuf};

fn repo_root() -> PathBuf {
    let mut dir = std::env::current_dir().expect("cwd readable");
    while !dir.join("PLAN.md").is_file() {
        dir = dir.parent().expect("run inside the repository").to_path_buf();
    }
    dir
}

fn resolve(root: &Path, file: &str) -> Option<PathBuf> {
    if file.ends_with(".rs") {
        let mut stack = vec![root.join("crates/ast-core/src")];
        let mut found = None;
        while let Some(dir) = stack.pop() {
            for entry in std::fs::read_dir(&dir).ok()? {
                let path = entry.ok()?.path();
                if path.is_dir() {
                    stack.push(path);
                } else if path.file_name().and_then(|f| f.to_str()) == Some(file) {
                    found = Some(path);
                }
            }
        }
        found
    } else {
        let path = root.join("reference/starlink-ast/src").join(file);
        path.is_file().then_some(path)
    }
}

fn main() {
    let root = repo_root();
    let args: Vec<String> = std::env::args().skip(1).collect();
    let write = args.iter().any(|a| a == "--write");
    let mut unanchored = 0usize;
    for arg in args.iter().filter(|a| !a.starts_with("--")) {
        let path = PathBuf::from(arg);
        let text = std::fs::read_to_string(&path).expect("checklist readable");
        let mut out = String::with_capacity(text.len());
        for (i, line) in text.lines().enumerate() {
            let mut rebuilt = line.to_string();
            for cell in line.split('|') {
                let Some(cit) = audit_tools::parse_citation(cell) else {
                    continue;
                };
                if cit.item.is_some() {
                    continue;
                }
                let Some(src_path) = resolve(&root, &cit.file) else {
                    continue;
                };
                let src = std::fs::read_to_string(&src_path).expect("source readable");
                let item = if cit.file.ends_with(".rs") {
                    audit_tools::enclosing_rust_item(&src, cit.start)
                } else {
                    audit_tools::enclosing_c_function(&src, cit.start)
                };
                match item {
                    Some(name) => {
                        let bare = match cit.end {
                            Some(e) => format!("{}:{}-{}", cit.file, cit.start, e),
                            None => format!("{}:{}", cit.file, cit.start),
                        };
                        rebuilt = rebuilt.replacen(&bare, &format!("{bare} (fn {name})"), 1);
                    }
                    None => {
                        unanchored += 1;
                        println!(
                            "{}:{}: {}:{} is not inside any item — re-anchor by hand",
                            path.display(),
                            i + 1,
                            cit.file,
                            cit.start
                        );
                    }
                }
            }
            out.push_str(&rebuilt);
            out.push('\n');
        }
        if write {
            std::fs::write(&path, out).expect("checklist writable");
        } else {
            print!("{out}");
        }
    }
    if unanchored > 0 {
        eprintln!("{unanchored} citations could not be anchored");
        std::process::exit(1);
    }
}
```

```rust
/// The `impl` header enclosing `line` (1-based), as `"Trait for Type"` when the
/// block implements a trait and `"Type"` when it does not.
///
/// This is what distinguishes a step that landed on a trait method — the port's
/// equivalent of a C vtab slot — from one that landed on an inherent helper.
pub fn enclosing_rust_impl(src: &str, line: usize) -> Option<String> {
    let mut stack: Vec<(String, usize)> = Vec::new();
    let mut depth = 0usize;
    let mut pending: Option<String> = None;
    for (i, text) in src.lines().enumerate() {
        let code = code_only(text);
        if let Some(header) = impl_header(&code) {
            pending = Some(header);
        }
        for c in code.chars() {
            match c {
                '{' => {
                    depth += 1;
                    if let Some(header) = pending.take() {
                        stack.push((header, depth));
                    }
                }
                '}' => {
                    if stack.last().is_some_and(|(_, d)| *d == depth) {
                        stack.pop();
                    }
                    depth = depth.saturating_sub(1);
                }
                _ => {}
            }
        }
        if i + 1 == line {
            return stack.last().map(|(header, _)| header.clone());
        }
    }
    None
}

/// The subject of an `impl` line, with generics and `where` clauses removed.
fn impl_header(code: &str) -> Option<String> {
    let trimmed = code.trim_start();
    let rest = trimmed.strip_prefix("impl")?;
    if rest.starts_with(|c: char| is_ident(c)) {
        return None;
    }
    let body = rest
        .split(" where ")
        .next()
        .unwrap_or(rest)
        .split('{')
        .next()
        .unwrap_or(rest);
    let mut out = String::new();
    let mut generic = 0i32;
    for c in body.chars() {
        match c {
            '<' => generic += 1,
            '>' => generic -= 1,
            _ if generic == 0 => out.push(c),
            _ => {}
        }
    }
    let header = out.split_whitespace().collect::<Vec<_>>().join(" ");
    (!header.is_empty()).then_some(header)
}
```

```rust
//! Enumerating the steps of a C seam body from the source.
//!
//! AST's house style precedes every step inside a function body with a comment
//! block starting at column 0. Deriving the steps from those comments keeps the
//! audit's universe of steps out of any hand-maintained list: a step that is
//! present in C and absent from a checklist is then a detectable omission
//! rather than an invisible one.

use crate::c_functions;

/// The line and text of each column-0 comment block inside `function`'s body.
///
/// A block's text is joined onto one line with runs of whitespace collapsed, so
/// a comment that wraps in the source compares as what it says.
pub fn c_step_comments(src: &str, function: &str) -> Vec<(usize, String)> {
    let lines: Vec<&str> = src.lines().collect();
    let Some((_, start, end)) = c_functions(src)
        .into_iter()
        .find(|(name, _, _)| name == function)
    else {
        return Vec::new();
    };
    let mut out = Vec::new();
    let mut i = start; // Skip the declarator line itself.
    while i + 1 < end {
        let text = lines[i];
        if !text.starts_with("/*") {
            i += 1;
            continue;
        }
        let first = i;
        let mut body = String::new();
        loop {
            body.push(' ');
            body.push_str(lines[i]);
            if lines[i].contains("*/") || i + 1 >= end {
                break;
            }
            i += 1;
        }
        let cleaned = body
            .trim()
            .trim_start_matches("/*")
            .trim_end_matches("*/")
            .split_whitespace()
            .collect::<Vec<_>>()
            .join(" ");
        out.push((first + 1, cleaned));
        i += 1;
    }
    out
}
```

## Cluster 1 — the `IsSimp` card

Three fixtures in this cluster: `cefit_circle_conformal` and
`cefit_circle_nonconformal_keep` (rows B in `SERIAL_UNGATED`, and two of the
seven `ISSIMP_DISAGREEMENTS` rows) and `neg_box_asymmetric_2d` (the single
`NO_ISSIMP_CARD_UNGATED` row).
They rest on two C rules the port does not have, both read off the pinned
source.

**Rule 1 — a Frame never reports `IsSimple`.**
`frame.c:5590` overrides the protected `astGetIsSimple` method and returns 0
unconditionally, "because Frames are not immutable (unlike non-Frame
Mappings)".
Every FrameSet and every Region inherits that override, so `mapping.c:23781`,
which writes the card only when `astGetIsSimple` is non-zero, never writes one
for a Frame-kind object however many times `astSimplify` has stamped it.
The port reproduces the *output* by accident — no Frame-kind class holds a
`SimplifiedRecord`, so the `Mapping` trait defaults at
`crates/ast-core/src/mappings/mod.rs:564-582` return `false` — but the harness
asserts the opposite, requiring a card on every simplified result
(`test_simplify_regression.rs:402-406`), and `neg_box_asymmetric_2d` is licensed
out of that wrong assertion rather than gated by the right one.

**Rule 2 — the card is discarded on load whenever the class's own loader routes
an attribute through a clearing setter.**
Upstream `e40e71b4` made a setter for an attribute that feeds the first part of
its class's own `astMapMerge` discard both simplified records
(`mapping.h:449-460`, PLAN.md §9.2).
Every loader for those classes assigns the attribute *through that setter* —
`astLoadZoomMap` at `zoommap.c:2238` calls `SetZoom`, whose `astMAKE_SET1` at
`zoommap.c:1704` calls `astClearIsSimple` — and `astLoadMapping` has already
installed the record from the `IsSimp` card by then (`mapping.c:24137`, which
runs in the parent before any class-specific card is read).
So for those classes a dumped `IsSimp = 1` does not survive being read back.

The corpus discriminates rule 2 on two matched pairs, same class and same
nesting depth, differing only in whether a clearing attribute is present:

| fixture | class | clearing attribute in the `.map` | `IsSimp` in C's `.simp` |
|---|---|---|---|
| `cefit_circle_conformal` | ZoomMap | `Zoom = 2` | absent |
| `cap_poly_unc_frame` | ZoomMap | `Zoom = 4` | present |
| `cefit_circle_nonconformal_keep` | MathMap | `SimpFI = 1`, `SimpIF = 1` | absent |
| `cap_poly_bent_edges` | MathMap | none | present |

The two "present" rows are not counter-examples, and they are this cluster's
negative controls.
Where the record is cleared on load, a card can still reappear, because
`astSimplify_` stamps whatever the vtab slot returns and the base `Simplify`
returns `astClone(this)` — the same pointer — so the stamp lands on the object
already in the tree.
`FrameSet::Simplify` keeps that stamp only when some edge reduced:
`astClone( simpler ? new : this )` at `frameset.c:10226` discards the whole deep
copy otherwise, stamps and all.
`cap_poly_unc_frame` reaches its ZoomMap through a path that adopts the copy;
`cefit_circle_conformal` does not, so its original — cleared at load — is what C
dumps.
That is the `flags = 0` object PLAN.md §9.1 saw and read as freshly constructed:
it is the original, and the constructor it was looking for does not exist.
`cap_poly_bent_edges` never loses the record at all, because its MathMap carries
no `SimpFI` / `SimpIF` / `Seeded` card and `TestSimpFI` is therefore false.

`FrameSet::simplified` (`crates/ast-core/src/frames/frameset.rs:1647-1670`)
already mirrors `frameset.c:10111` edge for edge, including the unconditional

pointer, so rule 2 is the only missing piece on the port side.

```c
/*
*  Name:
*     gen_simp

*  Purpose:
*     Read a native-format Object, simplify it, and write the result.

*  Description:
*     Reads one native-encoded Object from the named file, calls astSimplify on
*     it, and writes the result to the named output file. A FrameSet reads and
*     simplifies as a Mapping, so both the `.map` and the `.ast` inputs in the
*     simplify corpus work.
*
*     The output Channel's Comment and Indent attributes come from the two
*     optional trailing arguments, so a reference captured with either turned
*     off can be reproduced exactly.

*  Usage:
*     gen_simp <in> <out> [comment] [indent]
*/

#include "ast.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static FILE *src;
static char linebuf[4096];

static const char *srcfn( void ) {
   if( fgets( linebuf, sizeof linebuf, src ) ) {
      size_t n = strlen( linebuf );
      while( n && ( linebuf[ n - 1 ] == '\n' || linebuf[ n - 1 ] == '\r' ) ) {
         linebuf[ --n ] = 0;
      }
      return linebuf;
   }
   return NULL;
}

int main( int argc, char **argv ) {
   int comment = 1;
   int indent = 3;

   if( argc < 3 ) {
      fprintf( stderr, "usage: gen_simp <in> <out> [comment] [indent]\n" );
      return 2;
   }
   if( argc > 3 ) comment = atoi( argv[ 3 ] );
   if( argc > 4 ) indent = atoi( argv[ 4 ] );

   astBegin;

   src = fopen( argv[ 1 ], "r" );
   if( !src ) {
      fprintf( stderr, "gen_simp: cannot open %s\n", argv[ 1 ] );
      return 1;
   }
   AstChannel *in = astChannel( srcfn, NULL, "" );
   AstMapping *map = (AstMapping *) astRead( in );
   fclose( src );
   if( !map ) {
      fprintf( stderr, "gen_simp: read failed for %s\n", argv[ 1 ] );
      return 1;
   }

   AstMapping *simp = astSimplify( map );

   AstChannel *out = astChannel( NULL, NULL, "SinkFile=%s,Comment=%d,Indent=%d",
                                 argv[ 2 ], comment, indent );
   if( astWrite( out, simp ) != 1 ) {
      fprintf( stderr, "gen_simp: write failed for %s\n", argv[ 2 ] );
      return 1;
   }

   astEnd;
   return astOK ? 0 : 1;
}
```

Create `tools/oracle_fixtures/check_simplify_fresh.py`:

```python
"""Classify every simplify reference against a fresh capture from the pinned C.

Card-only drift means the reference predates a library change and must be
regenerated. Numeric drift means it was captured on another platform: it is
reported and tolerated, because regenerating it here would replace a
cross-platform reference with this machine's libm. Structural drift -- a
different nesting or a different class -- should never happen.

A negative fixture names its own input as its reference. Its fresh capture
differs by exactly the top-level ``IsSimp`` card that ``astSimplify_`` stamps on
every result, so that one line is discounted for those rows and for those rows
only.
"""

from __future__ import annotations

import re
import subprocess
import sys
from pathlib import Path

CARD = re.compile(r"^\s*([A-Za-z][A-Za-z0-9_]*)\s*=")
STRUCT = re.compile(r"^\s*(Begin|End|IsA)\s+(\S+)")

Row = tuple[str, str, str, int, int]


def parse_manifest(path: Path) -> list[Row]:
    """Return (name, input, reference, comment, indent) for every manifest row."""
    rows: list[Row] = []
    for raw in path.read_text().splitlines():
        line = raw.split("#", 1)[0].strip()
        if not line:
            continue
        fields = [f.strip() for f in line.split("|")]
        while len(fields) < 5:
            fields.append("")
        name, inp, ref, _skip, opts = fields[:5]
        comment, indent = 1, 3
        for item in (o.strip() for o in opts.split(",") if o.strip()):
            key, _, value = item.partition("=")
            if key.strip() == "comment":
                comment = int(value)
            elif key.strip() == "indent":
                indent = int(value)
            else:
                raise SystemExit(f"{name}: unknown render option {key!r}")
        rows.append((name, inp, ref, comment, indent))
    return rows


def shape(text: str) -> list[str]:
    """Return the structural skeleton: one token per Begin/End/IsA and card name."""
    out: list[str] = []
    for line in text.splitlines():
        found = STRUCT.match(line)
        if found:
            out.append(f"{found.group(1)} {found.group(2)}")
            continue
        found = CARD.match(line)
        if found:
            out.append(found.group(1))
    return out


def classify(ref: str, fresh: str, negative: bool) -> str:
    """Return 'fresh', 'numeric', 'card' or 'structural' for one comparison."""
    if negative:
        # The reference is the unsimplified input; discount the one card the
        # simplify result always gains, and nothing else.
        fresh_lines = fresh.splitlines()
        stamped = [i for i, l in enumerate(fresh_lines) if l.strip().startswith("IsSimp =")]
        if len(stamped) == 1:
            del fresh_lines[stamped[0]]
            fresh = "\n".join(fresh_lines) + "\n"
    if ref == fresh:
        return "fresh"
    ref_shape, fresh_shape = shape(ref), shape(fresh)
    if ref_shape != fresh_shape:
        classes_ref = [t for t in ref_shape if t.startswith(("Begin", "End", "IsA"))]
        classes_fresh = [t for t in fresh_shape if t.startswith(("Begin", "End", "IsA"))]
        return "structural" if classes_ref != classes_fresh else "card"
    return "numeric"


def main(argv: list[str]) -> int:
    """Compare every manifest row's reference against a fresh capture."""
    if len(argv) != 4:
        print("usage: check_simplify_fresh.py <corpus-dir> <gen_simp> <work-dir>")
        return 2
    corpus, driver, work = Path(argv[1]), Path(argv[2]), Path(argv[3])
    work.mkdir(parents=True, exist_ok=True)

    counts = {"fresh": 0, "numeric": 0, "card": 0, "structural": 0}
    for name, inp, ref, comment, indent in parse_manifest(corpus / "simplify_tests.txt"):
        out = work / f"{name}.freshC"
        result = subprocess.run(
            [str(driver), str(corpus / inp), str(out), str(comment), str(indent)],
            capture_output=True,
            text=True,
            check=False,
        )
        if result.returncode != 0:
            print(f"CAPTURE-FAILED {name}: {result.stderr.strip()}")
            counts["structural"] += 1
            continue
        verdict = classify(
            (corpus / ref).read_text(), out.read_text(), negative=(inp == ref)
        )
        counts[verdict] += 1
        if verdict != "fresh":
            print(f"{verdict.upper():>10} {name}")

    print(
        f"\n{counts['fresh']} fresh, {counts['numeric']} numerically drifted, "
        f"{counts['card']} card-drifted, {counts['structural']} structurally drifted"
    )
    if counts["card"] or counts["structural"]:
        print(
            "\nCard-drifted references predate a library change: regenerate them "
            "with gen_simp. Numeric drift is left alone -- regenerating it would "
            "bake this machine's libm into a cross-platform reference."
        )
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

- [ ] **Step 5: Add the licence and its comparator**

In `crates/ast-core/tests/test_simplify_regression.rs`, immediately after the
`ISSIMP_PLACEMENT_LICENSED` declaration, add:

```rust
/// Reference values captured on another machine, whose local recapture from the
/// pinned C differs by more than the 4-ulp token tolerance.
///
/// `tools/oracle_fixtures/check_simplify_fresh.sh` classifies these as numeric
/// drift, and the corpus-freshness rule keeps them: regenerating one here would
/// replace a cross-platform reference with this machine's libm. So the byte
/// comparison drops exactly the named card, on exactly the named fixture, and
/// only while both sides are cancellation residue — below the entry's bound in
/// absolute value, on an element whose row-mates are of order one.
///
/// `(fixture, card name, magnitude bound)`.
const NUMERIC_PLATFORM_DRIFT: &[(&str, &str, f64)] = &[(
    "rigby",
    "IM5",
    1e-15,
)];

/// Drop the lines one `NUMERIC_PLATFORM_DRIFT` entry licenses, from both sides.
///
/// A line is dropped only when its card name matches the entry and its value
/// parses below the entry's bound in absolute value. Exactly one line must be
/// dropped from each side; any other count is returned as a failure, so the
/// licence cannot widen to cover a card that grew, moved or multiplied.
fn drop_licensed_residue(name: &str, got: &str, want: &str) -> (String, String, Vec<String>) {
    let mut problems = Vec::new();
    let mut got = got.to_string();
    let mut want = want.to_string();

    for (fixture, card, bound) in NUMERIC_PLATFORM_DRIFT {
        if *fixture != name {
            continue;
        }
        let prefix = format!("{card} =");
        let residue = |line: &str| -> bool {
            let trimmed = line.trim_start();
            if !trimmed.starts_with(&prefix) {
                return false;
            }
            trimmed
                .split_once('=')
                .and_then(|(_, rest)| {
                    rest.split('\t').next().unwrap_or(rest).trim().parse::<f64>().ok()
                })
                .is_some_and(|v| v.abs() < *bound)
        };
        for (side, text) in [("got", &mut got), ("want", &mut want)] {
            let kept: Vec<&str> = text.lines().filter(|l| !residue(l)).collect();
            let dropped = text.lines().count() - kept.len();
            if dropped != 1 {
                problems.push(format!(
                    "{name}: NUMERIC_PLATFORM_DRIFT licenses one {card} residue below \
                     {bound:e}, but dropped {dropped} from the {side} side"
                ));
            }
            *text = kept.join("\n");
        }
    }

    (got, want, problems)
}
```

### Task 14: Keep the tag C raises on a nominated element

The tag is per orientation. `CmpMap::simplified` is a two-slot record and
`dump_is_simple` reads the slot for the object's *current* `Invert`
(`cmpmap.rs:903-909`), because that is the orientation the dump is about to
serialise. Two writers in `simplify.rs` set it, and only one of them accounts for
that:

- `simplify.rs:724`, on the path where the self-simplify *did* reduce something,
  writes `fwd.set_simplified_in(new_inv, true)` — the mapping is held forward and
  the tag goes into the slot for the orientation the tree will store it at. The
  comment there says exactly that.
- `simplify.rs:560-565`, `set_component_simple_tag`, on C's `!simpler` path,
  writes `cm.set_dump_simplified_in(cm.is_inverted(), true)`. A list entry is held
  in its forward orientation by [`flatten`]'s contract, so this always writes the
  forward slot — while the entry's serialised orientation is the third member of
  its tuple, `orig_inv`, which `reconstruct` re-applies to the child. When
  `orig_inv` is true the tag is written to one slot and read from the other.

That is candidate 1, and it is the one the shape of the code points at. Steps 1-2
discriminate it from the two alternatives before anything is changed, because a
tag that goes missing has three places it can go missing and picking by inspection
is what has been wrong here before.

```rust
/// `Invert = 1` on the reference side and exactly one `IsSimp = 1` on the port's,

        return (got.to_string(), want.to_string(), Vec::new());
    };

        let mut dropped = 0;
        let kept: Vec<&str> = text
            .lines()
            .filter(|l| {
                let hit = l.trim_start().starts_with(needle) && dropped == 0;
                if hit {
                    dropped += 1;
                }
                !hit
            })
            .collect();

                "{name}: INVAB_ALIASING_LICENSED covers one {needle} on the {side} \
                 side ({reason}), but found {dropped}"
            ));
        }
        kept.join("\n")
    };
    let got = trim(got, "IsSimp = 1", "port");
    let want = trim(want, "Invert = 1", "reference");
    (got, want, problems)
}
```

## Cluster 3 — Region simplify results and `astNormBox`

Four fixtures in this cluster produce a `.simp` that is not byte-equal to C's,
and three of the four turn out to have one cause: an uncertainty Region that
never passes through the port of `astSetUnc`.

C funnels every uncertainty through `SetUnc` (`region.c:10754`, body
`:10820-10910`), which does four things to the Region it is handed:

1. remaps it into the parent Region's **base** Frame, via `Conv` and
   `astMapRegion`;
2. negates it if it is unbounded, so the stored uncertainty is always bounded;
3. calls `astSetRegionFS( this->unc, 0 )` when the uncertainty's own
   base→current Mapping simplifies to a UnitMap — which is what omits the
   `FrmSet` block from its dump;
4. re-centres it at the parent Region's first defining point.

Three paths reach it in C. The constructor routes a construction-time
uncertainty through it (`region.c:13372`, `SetUnc( new, unc, status )`), so
every `astBox( frm, …, unc, … )` gets all four. `Region::Simplify` installs the
simplified uncertainty through it after the stability check
(`region.c:11303-11305`). The **loader** does not — `region.c:13559` stores what
the Channel read verbatim, so a Region read from a `.map` file keeps exactly
the uncertainty the file described.

The port has a faithful `astSetUnc` in `Region::set_uncertainty`
(`regions/mod.rs:345`) and `parent_region_simplify` calls it
(`mod.rs:1018`). What is missing is the constructor route: every builder writes
`data.uncertainty = self.uncertainty` directly, so a Region built with an
uncertainty gets none of the four steps. That is `cap_interval_01`'s `X7` (a
time uncertainty left in seconds where C converts it to days) and
`cap_pointlist_01`'s `X5`/`X6` (values passed through unchanged where C remaps
and re-centres them). The fourth fixture, `nullregion_unc_fillfactor_merge`, is
a self-confessed shortcut in `NullRegion::region_merge`; and `cap_zoommap_04`'s
59 inserted lines are step 3 not happening, which is also the last row of
`ISSIMP_DISAGREEMENTS`.

Two facts about these fixtures that must not be mistaken for defects:

- `cap_interval_01`'s `X5` and `X6` differ from the reference in the 12th
  significant figure, and the port agrees with a fresh capture from the pinned
  C to the last digit. That is the reference's platform drift, licensed in
  Task 12. **Those two values stay as they are.**
- Every capture from `cargo run -p ast-core --example simp_one` carries one
  extra trailing blank line. That is the example's own output, not the
  serializer's; the harness does not see it.

The cluster closes with the three unported `astNormBox` call sites, which are
the same subject from the other end: `Ellipse` and `Polygon` compute a base
Frame bounding box without asking the Frame to extend it over a singularity,
and `CmpFrame` has no override at all, so a box spanning a pole inside a
compound Frame is never extended.

### Task 20: `Ellipse` bounds come from the mesh, as C's do

**Files:**
- Modify: `crates/ast-core/src/regions/ellipse.rs:465-481`
- Test: `crates/ast-core/tests/test_region.rs` (new test, Step 1)

**Interfaces:**
- Consumes: `Frame::ax_distance(&self, axis: usize, v1: f64, v2: f64) -> AstResult<f64>`
  (`frames/mod.rs:854`); `Frame::norm_box(&self, lbnd: &mut [f64], ubnd: &mut [f64], inside: &dyn Fn(&[f64]) -> AstResult<bool>) -> AstResult<()>`

  (the cached wrapper at `ellipse.rs:752`).
- Produces: no signature change. `reg_base_box(&self) -> AstResult<(Vec<f64>, Vec<f64>)>`
  keeps its shape; only its algorithm changes.

C's `Ellipse::RegBaseBox` (`ellipse.c:933-999`) computes nothing. It forces the
mesh to exist —

```c
   if( !this_region->basemesh ) (void) astAnnul( astRegBaseMesh( this ) );
```

— and then reads the four numbers `RegBaseMesh` cached while generating it. The
bounds are therefore the bounds *of the mesh points*, accumulated with
`astAxDistance` as offsets from the ellipse centre, and passed through
`astNormBox` before being cached (`ellipse.c:1180-1198`).

The port computes a closed-form Cartesian extent instead:

```rust
        let x_extent = ((a * cos_a).powi(2) + (b * sin_a).powi(2)).sqrt();
```

That is right for a plain 2-d Frame and wrong for a SkyFrame, where the mesh is
a geodesic ellipse, the extents are not symmetric about the centre, and a box
containing a pole must be widened to the full longitude range. `Circle` already
does it C's way (`circle.rs:340-377`); this task brings `Ellipse` into line.

Two C details the port must keep:

- `astAxDistance( frm, 1, this->centre[ 1 ], p2[ 1 ] )` — C passes **axis 1**
  when accumulating the axis-2 bounds (`ellipse.c:1190`). On a SkyFrame that is
  the longitude axis's wrapping rule applied to a latitude difference. It is a C
  bug; mirror it, as `Circle` does not need to because it passes 1 and 2
  correctly there, and log it in the quirks doc.
- The accumulation is `if dist < lb { lb = dist } else if dist > ub { ub = dist }`
  — an `else if`, so a point that would extend both ends only extends the lower
  one. With `lb` initialised to `DBL_MAX` and `ub` to `-DBL_MAX`, the first point
  sets only `lb`. Mirror the asymmetry.

```rust
        // C computes nothing here: it forces the base mesh to exist and reads
        // the bounds RegBaseMesh accumulated while generating it
        // (ellipse.c:933-999). `get_region_mesh` is the cached mesh, so the
        // points below are the same points, in the same order.
        let mesh = self.get_region_mesh()?;
        let centre = &self.data.points[0];
        let frm = self.data.frameset.base();

        let mut lbx = f64::MAX;
        let mut ubx = -f64::MAX;
        let mut lby = f64::MAX;
        let mut uby = -f64::MAX;

        for ip in 0..mesh.npoint() {
            let p2 = mesh.point(ip);

            // Bounds are accumulated as offsets from the centre, using
            // astAxDistance so that a cyclic axis wraps correctly
            // (ellipse.c:1185-1196). C's `else if` means a point that would
            // extend both ends of an axis extends only the lower one; and C
            // passes axis 1 for both axes, which on a SkyFrame applies the
            // longitude wrapping rule to a latitude difference. Both are
            // mirrored: see docs/issues/c-library-quirks.md.
            let dist = frm.ax_distance(1, centre[0], p2[0])?;
            if dist < lbx {
                lbx = dist;
            } else if dist > ubx {
                ubx = dist;
            }

            let dist = frm.ax_distance(1, centre[1], p2[1])?;
            if dist < lby {
                lby = dist;
            } else if dist > uby {
                uby = dist;
            }
        }

        let mut lower = vec![centre[0] + lbx, centre[1] + lby];
        let mut upper = vec![centre[0] + ubx, centre[1] + uby];

        // Extend the box to include the effect of any coordinate-system
        // singularities. C builds the probe by copying the Ellipse, giving it
        // the base Frame and clearing Negated (ellipse.c:1198-1203), so the
        // predicate is membership of the un-negated Ellipse.
        let (a, b, angle) = self.ellipse_params()?;
        let cos_a = angle.cos();
        let sin_a = angle.sin();
        let closed = self.data.closed;
        let inside = |point: &[f64]| -> AstResult<bool> {
            if crate::constants::is_bad(point[0]) || crate::constants::is_bad(point[1]) {
                return Ok(false);
            }
            let dx = point[0] - centre[0];
            let dy = point[1] - centre[1];
            let u = dx * cos_a + dy * sin_a;
            let v = -dx * sin_a + dy * cos_a;
            let d = u * u / (a * a) + v * v / (b * b);
            Ok(if closed { d <= 1.0 } else { d < 1.0 })
        };
        frm.norm_box(&mut lower, &mut upper, &inside)?;

        Ok((lower, upper))
    }
```

  (`cmpframe.rs:219`), `CmpFrame::frame1(&self) -> &dyn Frame` (`:231`),
  `CmpFrame::frame2(&self) -> &dyn Frame` (`:236`).
- Produces: `fn norm_box(&self, lbnd: &mut [f64], ubnd: &mut [f64], inside: &dyn Fn(&[f64]) -> AstResult<bool>) -> AstResult<()>`
  on `CmpFrame`, overriding the `Frame` default (`frames/mod.rs:1119`).

`CmpFrame` has no `norm_box`, so it inherits the do-nothing default. A Region on
a `CmpFrame(SkyFrame, TimeFrame)` therefore never gets its pole widening — the
component SkyFrame's override (`skyframe.rs:1261`) is never reached. C
overrides it (`cmpframe.c:5830`): permute the bounds into internal order, split
them at `naxes1`, and call each component Frame's `astNormBox` with a probe
Mapping that expands a component sub-position back into a full external position
before applying the caller's `reg`.

C builds those probes out of PermMaps, and the second one is malformed. The
sub-position for `frame2` is expanded by

```c
      for( axis = 0; axis < naxes - naxes1; axis++ ) inperm[ axis ] = naxes1 + axis;
      pm3 = astPermMap( naxes1, inperm, naxes, NULL, NULL, "", status );
```

`nin` is `naxes1`, not `naxes - naxes1`; and with a NULL `outperm` a PermMap's
forward transformation is the identity as far as it goes — `PERMVAL` at
`permmap.c:159` gives output *i* from input *i* while `i < nin`, and `AST__BAD`
after that. So the forward transformation places `frame2`'s coordinates at
internal axes `0 .. naxes1-1`, which are `frame1`'s axes. The inverse, which uses
`inperm`, extracts the right axes. Only the forward direction matters for the
probe, so `frame2`'s `astNormBox` receives a predicate that tests the wrong
axes.

Confirm that against the oracle before porting it, then mirror what the oracle
does and record it.

```rust
    /// Extend a box to include the effect of singularities in either component
    /// Frame. Faithful port of C `CmpFrame::NormBox` (cmpframe.c:5830): the
    /// bounds are permuted into internal order, split at the first component's
    /// axis count, and each component's `norm_box` is called with a predicate
    /// that expands a component sub-position back into a full external position
    /// before consulting the caller's predicate.
    fn norm_box(
        &self,
        lbnd: &mut [f64],
        ubnd: &mut [f64],
        inside: &dyn Fn(&[f64]) -> AstResult<bool>,
    ) -> AstResult<()> {
        let naxes = self.naxes();
        let naxes1 = self.naxes1();
        let perm = self.perm();

        // Permute into the order the component Frames use internally
        // (cmpframe.c:5941-5944).
        let mut vl = vec![0.0; naxes];
        let mut vu = vec![0.0; naxes];
        for axis in 0..naxes {
            vl[perm[axis]] = lbnd[axis];
            vu[perm[axis]] = ubnd[axis];
        }

        // C composes pm1 . reg . pm1^-1 so the caller's Mapping can be applied
        // to an internal-order position (cmpframe.c:5950-5960); here that is
        // just the un-permutation below, applied inside each predicate.
        let external = |internal: &[f64]| -> Vec<f64> {
            (0..naxes).map(|axis| internal[perm[axis]]).collect()
        };

        // The first component's predicate: place the sub-position at internal
        // axes 0..naxes1 and fill the rest with BAD, which is what pm2's
        // forward transformation does (cmpframe.c:5966-5967).
        let inside1 = |point: &[f64]| -> AstResult<bool> {
            let mut internal = vec![BAD_VALUE; naxes];
            for (i, v) in point.iter().take(naxes1).enumerate() {
                internal[i] = *v;
            }
            inside(&external(&internal))
        };
        self.frame1().norm_box(&mut vl[..naxes1], &mut vu[..naxes1], &inside1)?;

        // The second component's predicate. C's pm3 is declared with
        // nin = naxes1 rather than naxes - naxes1, and its NULL outperm makes
        // the forward transformation copy input i to output i (permmap.c:159),
        // so the second component's coordinates land on the *first*
        // component's internal axes. Mirrored to keep the corpus byte-exact;
        // see docs/issues/c-library-quirks.md.
        let inside2 = |point: &[f64]| -> AstResult<bool> {
            let mut internal = vec![BAD_VALUE; naxes];
            for (i, v) in point.iter().take(naxes1).enumerate() {
                internal[i] = *v;
            }
            inside(&external(&internal))
        };
        self.frame2()
            .norm_box(&mut vl[naxes1..], &mut vu[naxes1..], &inside2)?;

        // Un-permute (cmpframe.c:5990-5993).
        for axis in 0..naxes {
            lbnd[axis] = vl[perm[axis]];
            ubnd[axis] = vu[perm[axis]];
        }

        Ok(())
    }
```

`BAD_VALUE` is already imported in this file; if it is not, add
`use crate::constants::BAD_VALUE;`. The two closures are deliberately identical
in body — that identity *is* the C bug, and collapsing them into one would hide
which of the two is meant to differ.

```markdown
## `CmpFrame::NormBox` expands the second component's box onto the first's axes

`cmpframe.c:5980-5981` builds the probe Mapping for the second component Frame as

    for( axis = 0; axis < naxes - naxes1; axis++ ) inperm[ axis ] = naxes1 + axis;
    pm3 = astPermMap( naxes1, inperm, naxes, NULL, NULL, "", status );

with `nin = naxes1` where the loop fills `naxes - naxes1` entries, and with a
NULL `outperm`, whose forward transformation copies input *i* to output *i* while
`i < nin` and supplies `AST__BAD` after that (`permmap.c:159`). The second
component's sub-position therefore arrives on the *first* component's internal
axes. The inverse, built from `inperm`, extracts the correct axes, so only the
forward direction — the one the probe uses — is affected.

The equivalent `pm2` for the first component is well-formed, so a CmpFrame
normalises a box correctly when the singular Frame is `frame1` and not when it is
`frame2`. A C-oracle probe over `CmpFrame(SkyFrame, TimeFrame)` and
`CmpFrame(TimeFrame, SkyFrame)` confirms the asymmetry.

The port mirrors it (`frames/cmpframe.rs`, `norm_box`) to keep the simplify
corpus byte-exact. Worth raising upstream together with the `Ellipse`
`astAxDistance` axis index.
```
