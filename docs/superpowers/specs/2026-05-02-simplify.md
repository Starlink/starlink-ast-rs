# Mapping Simplification — Design Spec

## Summary

Implement the full mapping simplification engine: CmpMap flattening,
iterative merge loop with pattern detection, and per-class merge
rules for all 15 mapping types. This is the core optimization that
collapses complex mapping chains into simpler equivalents — e.g.,
removing UnitMaps, accumulating ZoomMaps, cancelling inverse pairs.

## Deliverables

1. `simplify.rs` module — flatten, merge loop, reconstruct.
2. `try_merge` method on the Mapping trait (default returns None).
3. Per-class `try_merge` implementations for all applicable types.
4. Updated `CmpMap::simplified()` to use the new engine.
5. Updated `FrameSet::simplified()` to simplify edge mappings.
6. Comprehensive tests including LSST benchmark validation.

## Mapping Trait Addition

```rust
pub trait Mapping: AsAny + Send + fmt::Debug {
    // ... existing methods ...

    /// Attempt to merge this mapping with an adjacent mapping
    /// during simplification.
    ///
    /// `other` is the adjacent mapping. `series` is true for series
    /// composition, false for parallel. `self_inv` and `other_inv`
    /// are the effective inversion states in the composition.
    ///
    /// Returns `Some(merged)` if this mapping can absorb `other`.
    /// The merged result replaces both mappings in the flattened
    /// list. Returns `None` if no merge is possible.
    fn try_merge(
        &self,
        _other: &dyn Mapping,
        _series: bool,
        _self_inv: bool,
        _other_inv: bool,
    ) -> Option<DynMapping> {
        None
    }
}
```

Default returns None — non-breaking addition. Types that don't
support merging need no changes.

## Core Engine (simplify.rs)

### Flatten

```rust
pub(crate) fn flatten(
    mapping: &dyn Mapping,
    inv: bool,
    series: bool,
) -> Vec<(DynMapping, bool)>
```

Recursively decomposes CmpMap trees into a flat list of
(mapping, effective_invert) pairs. Only expands CmpMaps whose
composition mode (series/parallel) matches the requested mode.

For a CmpMap in series with invert=true:
- Swap the order of children (reverse the chain)
- Flip both children's effective invert flags

For non-CmpMap mappings: return a single-element list with the
mapping cloned and the invert flag.

### Merge Loop

```rust
pub(crate) fn merge_loop(
    list: &mut Vec<(DynMapping, bool)>,
    series: bool,
)
```

Iterative process:
1. Walk through adjacent pairs `(list[i], list[i+1])`.
2. For each pair, try:
   a. **General inverse-pair cancellation**: if same type, one
      inverted and one not, and `equal` ignoring inversion →
      replace both with UnitMap.
   b. **Left absorbs right**: `list[i].try_merge(list[i+1], ...)`
   c. **Right absorbs left**: `list[i+1].try_merge(list[i], ...)`
3. If a merge succeeds: replace the pair with the result, remove
   the consumed entry, mark `improved = true`, and continue from
   the modified position (don't advance past it).
4. If no merge: advance to next pair.
5. Repeat until a full pass produces no improvements.
6. **Pattern detection**: If a position oscillates (merge then
   un-merge on next pass), freeze it to prevent infinite loops.
7. Final cleanup: remove UnitMaps from series lists (they're
   identity and don't affect the result).

### Reconstruct

```rust
pub(crate) fn reconstruct(
    list: Vec<(DynMapping, bool)>,
    series: bool,
) -> AstResult<DynMapping>
```

Build a CmpMap tree from the flat list:
- Single element → return it (applying invert if needed).
- Multiple elements → fold into CmpMap chain.
- Empty list → UnitMap.

### Public Entry Point

```rust
pub(crate) fn simplify_mapping(mapping: &dyn Mapping) -> AstResult<DynMapping>
```

Orchestrates flatten → merge_loop → reconstruct. Used by
CmpMap::simplified().

## Per-Class Merge Rules

### UnitMap

**Series**: UnitMap can always be removed (it's identity). Return
the other mapping unchanged. This is handled by the post-loop
cleanup (remove UnitMaps from series lists) rather than by
try_merge.

**Parallel**: UnitMap + UnitMap → UnitMap(combined ncoord).

### ZoomMap

**Series with ZoomMap**: ZoomMap(a) + ZoomMap(b) → ZoomMap(a*b).
Account for inversion: effective factor is `factor` if not inverted,
`1/factor` if inverted. If product ≈ 1.0 (within ast_equal
tolerance) → UnitMap.

**Series with UnitMap**: Absorbed by UnitMap cleanup.

### ShiftMap

**Series with ShiftMap**: ShiftMap(a) + ShiftMap(b) → ShiftMap(a+b).
Account for inversion: effective shifts are negated when inverted.
If all sums ≈ 0.0 → UnitMap.

### WinMap

**Series with WinMap**: Compose linear transforms:
`out = s2*(s1*x + a1) + a2` → WinMap(shifts=s2*a1+a2, scales=s2*s1).
Account for inversion on each side.

**Series with ZoomMap**: ZoomMap is WinMap with shifts=0. Compose.

**Series with ShiftMap**: ShiftMap is WinMap with scales=1. Compose.

If result has all scales=1 and shifts=0 → UnitMap.

### MatrixMap

**Series with MatrixMap**: MatrixMap(A) + MatrixMap(B) → MatrixMap(B·A)
(B is applied after A). Account for inversion (inverted MatrixMap
uses its inverse matrix as the forward matrix).

If result is identity matrix (within tolerance) → UnitMap.

### PermMap

**Series with PermMap**: Compose permutation arrays. The output
permutation of the first feeds into the input permutation of the
second.

### PolyMap

**Inverse-pair only**: PolyMap + inverse(PolyMap) → UnitMap if
equal. No polynomial composition (too complex, minimal benefit).

### ChebyMap, LutMap

No merging. Return None.

### WcsMap

**Inverse-pair only**: WcsMap(TAN) + WcsMap(TAN)^-1 → UnitMap if
same projection type and parameters.

### SlaMap

**Inverse-pair only**: SlaMap + inverse(SlaMap) → UnitMap if equal.

### SphMap

**Inverse-pair cancellation**: SphMap + SphMap^-1 → UnitMap.
This is the critical optimization for the LSST FrameSet where
the mapping chain contains SphMap(Cartesian→spherical) followed
by SphMap^-1(spherical→Cartesian) with nothing in between after
other merges.

## CmpMap::simplified() Update

Replace the current `simplified()` (which just recursively
simplifies children) with a call to the simplification engine:

```rust
fn simplified(&self) -> AstResult<DynMapping> {
    simplify_mapping(self)
}
```

The engine handles recursive simplification internally via the
flatten step.

## FrameSet::simplified() Update

Currently returns the base→current composed mapping. Update to
simplify the result:

```rust
fn simplified(&self) -> AstResult<DynMapping> {
    let composed = self.mapping(FrameRef::Base, FrameRef::Current)?;
    composed.simplified()
}
```

## Testing Strategy

### Unit tests (in simplify.rs #[cfg(test)])

- Flatten CmpMap(CmpMap(A, B), C) → [A, B, C]
- Flatten inverted CmpMap → reversed list with flipped flags
- Flatten parallel CmpMap
- Reconstruct from 1, 2, 3 element lists

### Integration tests (test_simplify.rs)

**UnitMap removal:**
- CmpMap(UnitMap(2), ZoomMap(2, 3.0), Series) → ZoomMap(2, 3.0)
- CmpMap(ZoomMap, UnitMap, Series) → ZoomMap

**ZoomMap accumulation:**
- CmpMap(Zoom(2), Zoom(3), Series) → Zoom(6)
- CmpMap(Zoom(2), Zoom(0.5), Series) → UnitMap
- CmpMap(Zoom(2), Zoom(3), Zoom(4), Series) → Zoom(24)

**ShiftMap accumulation:**
- CmpMap(Shift(1,2), Shift(3,4), Series) → Shift(4,6)
- CmpMap(Shift(1,2), Shift(-1,-2), Series) → UnitMap

**WinMap composition:**
- CmpMap(WinMap, WinMap, Series) → WinMap(composed)
- CmpMap(WinMap, ZoomMap, Series) → WinMap

**MatrixMap multiplication:**
- CmpMap(MatrixMap(A), MatrixMap(B), Series) → MatrixMap(B·A)

**Inverse cancellation:**
- CmpMap(SphMap, SphMap^-1, Series) → UnitMap
- CmpMap(WcsMap(TAN), WcsMap(TAN)^-1, Series) → UnitMap
- CmpMap(ZoomMap(3), ZoomMap(3)^-1, Series) → UnitMap

**Deep nesting:**
- CmpMap(CmpMap(Zoom(2), Zoom(3)), CmpMap(Shift(1), Shift(2))) →
  CmpMap(Zoom(6), Shift(3))

**No-op:**
- UnitMap → UnitMap (already simple)
- ZoomMap(3) → ZoomMap(3) (already atomic)

**LSST benchmark validation:**
- Parse lsst.ast, get FrameSet mapping
- Call simplified()
- Verify simplified mapping produces same transform results
  (within tolerance) for test points
- Verify simplified mapping has fewer components
- Re-run benchmark timing to measure speedup

## What This Does NOT Include

- `astMapList` as a public API (internal to simplify.rs).
- Parallel-mode simplification (series is the priority; parallel
  is less common and can be added later).
- Cross-type merges beyond what's listed (e.g., MatrixMap absorbing
  ZoomMap — can be added incrementally).
- PolyMap polynomial composition (too complex for first pass).
- Pattern detection with full history tracking (simplified frozen
  flags sufficient for initial implementation).
